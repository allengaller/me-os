## 使用指南

### 入门路径
1. 先读 [01-品牌心理学.md](01-品牌心理学.md) 理解品牌的心理学基础
2. 再读 [02-个人定位深挖.md](02-个人定位深挖.md) 确定你的品牌定位
3. 然后读 [03-视觉识别系统.md](03-视觉识别系统.md) 建立品牌视觉
4. 接着读 [04-叙事与故事力.md](04-叙事与故事力.md) 掌握品牌叙事
5. 最后读 [05-信任构建体系.md](05-信任构建体系.md) 建立品牌信任

### 进阶路径
1. 读 [06-品牌危机管理.md](06-品牌危机管理.md) 预防和管理品牌危机
2. 读 [07-品牌资产评估.md](07-品牌资产评估.md) 评估品牌资产
3. 读 [08-全球个人品牌案例.md](08-全球个人品牌案例.md) 学习全球最佳实践

### 实践路径
1. 选择 1-2 个章节深入学习
2. 应用章节中的方法和工具
3. 测试和优化你的品牌策略
4. 分享你的品牌经验
