# 03-2 内容方法：把创作变成流水线

> 一句话：**灵感的产出不可控，系统的产出可控。
> 内容方法 = 支柱（方向）× 漏斗（筛选）× 公式（结构）× 一鱼多吃（杠杆）× 检查（质量门）。**

---

## 1. 内容支柱（Content Pillars，已定稿）

四条支柱，每条有固定供给义务，防止内容漂移：

| 支柱 | 一句话 | 代表形式 | 供给频率参考 |
|---|---|---|---|
| 极致工程方法论 | 第一性原则与 maxing everything 的框架和应用 | 长文/拆解视频/系统课 | 每月 1-2 |
| 田野调查实录（主线） | 各行各业真实反馈进视频 | 实地/访谈长视频 | 每月 1-2 |
| 自我调教日志 | 身体/认知/AI Agent 的公开调教与数据 | 周期短片/图文 | 每周 |
| 公开构建 | 出版物/App/小程序的构建与发布 | 开发日志/演示 | 双周 |

**支柱纪律**：
- 每条内容都有且仅有一个主支柱（Control：ContentItem 的 pillar 字段）；
- 季度检查覆盖均衡度：支柱失衡 = 定位漂移的信号，比单条数据更重要。

---

## 2. 选题漏斗（六步，配优先级）

```
① 收集（来源）：田野见闻 / 观众反馈（评论、私信）/ 极致工程中的矛盾点 /
                支柱覆盖补位 / 行业观察
② 登记：进选题库（未筛选题池，注明来源与直觉价值）
③ 四问筛选（全部通过才立项）：
    Q1 有真实反馈可验证？      （不是二手观点）
    Q2 能拆到第一性？          （故事之外有理）
    Q3 观众能照做？            （有落地动作）
    Q4 符合调性三关键词？      （接近真实 / 接地气 / 有依据）
④ 优先级：高 = 真实反馈 × 高普适；中 = 单点深入；低 = 过程记录
⑤ 立项：进 ContentItem（选题 → 创作 → 审校 → 发布）
⑥ 复盘：发布后写 reviewNote，其结论回流为 ① 的新来源（闭环）
```

**漏斗口径（行业惯例参考）**：每周入库 10-15 条 → 立项 2-3 条 → 成片 1-2 条。
库不够深是选题焦虑的来源——永远保持 2-3 个月的选题库存。

---

## 3. 内容公式（视频主线）

```
钩子 → 现场 → 真实反馈 → 第一性拆解 → 落地 → 互动
```

| 段 | 作用 | 规范 |
|---|---|---|
| 钩子 | 前 3 秒留下 | 真实问题/反直觉发现；**禁用**夸张手法与标题党 |
| 现场 | 建立可信 | 实拍 + 原声，保留环境音与过程 |
| 真实反馈 | 核心资产 | 受访者原话上屏，不替代、不改写 |
| 第一性拆解 | 提供「为什么」 | 事实→约束→结论，指回证据 |
| 落地 | 提供「怎么做」 | 可照做的清单/步骤/工具 |
| 互动 | 闭环田野 | 请观众提供反馈——反馈本身即田野 |

**长文公式**（衍生形态）：结论先行（TL;DR）→ 现场故事 → 数据与证据 →
方法拆解 → 可执行清单 → 引用与局限说明。

---

## 4. 一鱼多吃（内容复用矩阵）

> 原则（品牌蓝本 §6.7）：**内容不变，形态变；不为一平台改立场。**

```
长视频（主资产）
 ├─ 切片/口播短片      抖音/视频号（前 3 秒给结论）
 ├─ 图文长文           公众号（结构完整、可收藏）
 ├─ 原话金句 + 图文     小红书（少术语、视觉第一）
 ├─ 观点短帖            X（数据、进度、复盘片段，可英文）
 ├─ newsletter 摘要     订阅（私域沉淀）
 └─ 出版物素材库        长期（季度级整理进作品库）
```

**制作顺序纪律**：先做「主资产」（长视频/长文），再从主资产切一切——
不要为每个平台单独生产，否则产能与调性都守不住。

---

## 5. 质量门：编辑检查清单（发布前强制）

- [ ] 调性三关键词全会过？（接近真实 / 接地气 / 有依据）
- [ ] 证据、数据、出处齐备；绝对化断言已清除（扫描词表：最强/没有之一/必看/震惊/最后一天）
- [ ] 受访者同意清单已走完（如适用）
- [ ] 标题与封面符合规范（真实具体带现场；禁止震惊体）
- [ ] 一鱼多吃与平台适配已规划（各渠道形态与语气微调）
- [ ] 一致性检查：署名换成别人是否成立？

**标题规范**（蓝本 §5.6）：句式偏好「我去 X 干了 Y」「跟 Z 聊了 N 小时，发现…」
**封面规范**：现场实拍 + 大字标题；统一字体与构图系统；不用夸张表情与红圈箭头。

## 6. 内容供给的节奏（基线，可按产能调）

| 周期 | 内容 | 支柱 |
|---|---|---|
| 每周 | 自我调教日志 / 短文 | 调教 |
| 双周 | build in public 进度 | 公开构建 |
| 每月 | 田野长视频 1-2 条；深度图文 2-4 篇；月度复盘 | 田野 + 方法论 |
| 每季度 | 定位与支柱校准（回看本文件与 DESIGN.md） | 系统 |

**降级规则**：产能不足时先保「田野长视频 + 调教日志」两条主线；
宁可调低频率，不发达不到质量门的注水内容（质量门不可妥协，频率可以）。

## 6.1 试点条款 B1：长文晋升第二主资产（迁移自 06 全球思维库）

> 机制来源：写作即思考（Perell）+ 权威外化（刘润）+ 内容引擎（Justin Welsh）。
> 本 IP 当前图文是视频的「衍生形态」；试点目标是验证「长文独立成主资产」后，
> 回看率与高价值评论是否优于切片化图文。

| 项 | 内容 |
|---|---|
| 目标 | 每周 1 篇「田野方法论长文」（1000-2000 字，结论先行结构） |
| 验证指标 | 90 天回看率、高价值评论占比、被转载/引用次数 |
| 时间窗 | 连续 8 周（下一个季度内） |
| 步骤 | ① 长文独立立项（不依赖视频素材，主题从调教日志与方法论支柱取）→ ② 按长文公式产出（结论先行 → 现场故事 → 证据 → 方法 → 清单 → 局限）→ ③ 公众号首发 → ④ 周复盘中跟踪指标 |
| 退出条件 | 8 周后回看率 ≤ 同周期视频切片，则降级回「衍生形态」并记入复盘 |

## 7. 内容方法自检

- [ ] 选题库深度 ≥ 2 个月？
- [ ] 本周立项是否全部通过四问？
- [ ] 每条内容是否标注主支柱？支柱覆盖均衡吗？
- [ ] 主资产与衍生形态的生产顺序对不对（先主后切）？
- [ ] 发布前质量门全部过关？
