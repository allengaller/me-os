# 03-5 复盘与迭代方法：让每一期都成为下一期的地基

> 一句话：**不复盘的创作是重复劳动，复盘的创作是复利劳动。
> 本节的闭环是：reviewNote（每期）→ 月度复盘（渠道与数据）→ 季度校准（定位与调性）。**

---

## 1. 三层复盘节奏

```
┌────────────────────────────────────────────────┐
│ 季度：定位与调性校准（DESIGN.md 重读 + 支柱审计） │
│      ▲                                          │
│ 月度：渠道与数据复盘（快照趋势 + 漏斗诊断）      │
│      ▲                                          │
│ 每期：reviewNote（什么有效 / 下次改进）          │
└────────────────────────────────────────────────┘
```

| 层 | 周期 | 回答 | 产物 |
|---|---|---|---|
| 期复盘 | 每条内容 | 这条本身做对做错了什么 | reviewNote |
| 月复盘 | 每月 | 这个月趋势与结构如何 | 数据快照 + 调整清单 |
| 季校准 | 每季 | 方向还对吗？方法还灵吗 | 校准记录 + 方法更新 |

---

## 2. 期复盘：reviewNote 模板（发布 3-7 天后写）

```
┌─ reviewNote ──────────────────────────────────────────┐
│ 内容：____________________ 支柱：____________________  │
│ 数据：播放____ 完播____ 评论____ 收藏____ 导入私域____ │
│                                                       │
│ ① 什么有效？   （钩子？现场感？某段原话？某张图？）     │
│ ② 什么无效？   （开头？节奏？落地方案太虚？）           │
│ ③ 观众反馈里有什么线索？  （高价值评论逐条记录）        │
│ ④ 下次改进：（≤3 条，可验证）                          │
│ ⑤ 伦理与一致性自检（同意/更正/署名替换）               │
└───────────────────────────────────────────────────────┘
```

**纪律**：每条必写（Console 内置复盘区）；5 分钟内能写完，不许拖；
改进项 ≤3 条——贪多等于没有。

## 3. 月复盘：模板（每月最后一周，45 分钟）

### 3.1 数据驾驶舱
| 指标 | 本月 | 上月 | 趋势 | 解读 |
|---|---|---|---|---|
| 发布数（分形态） | | | | |
| 总播放/阅读 | | | | |
| 月新增粉丝 | | | | |
| 完播率中位数 | | | | |
| 高价值评论数 | | | | |
| 90 天回看率 | | | | |
| 私域净增 | | | | |
| 田野场次 | | | | |

### 3.2 五问
1. **北极星动了吗**？影响力与质量（回看率）——没动就先别谈战术优化。
2. **哪个环节在漏**？漏斗哪一层转化最差（曝光→观看→关注→沉淀）→ 只修最漏的一层。
3. **支柱均衡吗**？月度支柱覆盖饼图。
4. **哪些 reviewNote 的改进项兑现了**？兑现率 <60% = 改进项定得太贪。
5. **下个月的三个主题词**？（方向先行，选题跟进）

### 3.3 输出
- 下月选题清单（补位薄弱支柱）；
- 渠道健康表更新（对应 4-分发与增长方法 §2）；
- 一份「继续做 / 停止做 / 开始做」清单。

---

## 4. 季校准：模板（每季度最后一周，90 分钟）

### 4.1 核对品牌蓝本
- 重读 [DESIGN.md](../../brand/DESIGN.md)：定位陈述、调性、支柱——还能一字不差复述吗？
  背不出 = 定位在稀释，优先收敛。
- 逐条走「待定事项清单」（slogan/视觉/handle 等，DESIGN.md §10）。

### 4.2 三个审计
1. **支柱审计**：四支柱覆盖率与质量分布（哪个支柱最弱、为什么）；
2. **样本审计**：田野受访者画像分布（行业/立场/地域/性别）——偏斜即新选题；
3. **方法审计**：03 层的方法哪些灵、哪些失效（有数据或至少 3 次使用记录才表态）。

### 4.3 哲学自检（防偏离）
- 五条信念逐条自问：本季度有没有任何输出触碰了边界？
- 伦理事件记录（更正/撤回/争议）复盘——这些是系统健康度的信号。

### 4.4 输出
- 校准记录（改了哪些表达，保留了哪些内核）；
- 下一季度战略主题（1 个主攻方向 + 2 个防守方向）。

---

## 5. 迭代的元规则（复盘如何变好）

1. **每项改进可验证**：改进项必须有测量方式（「开头改短」→「前 3 秒完播率」）。
2. **一次只改一个变量**：方法论内容上同频共振（对应 极致工程：一个周期一个变量）。
3. **数据 > 感觉**：感觉会偏好近期记忆，数据会告诉你真相。
4. **把复盘本身做成内容**：月度复盘摘要（数据 + 3 个结论 + 1 个公开承诺）是
   「公开构建」支柱的稳定供给——鸡生蛋：复盘既是方法也是内容。
5. **复盘结论回流选题库**：每个无效发现都可能是下一篇的钩子（「上个月我被打脸的事」）。

---

## 6. 复盘自检

- [ ] 最近 10 条内容 reviewNote 完成率 100%？
- [ ] 上次月复盘的「开始做」清单执行了吗？
- [ ] 我能否说出这个月最有效的一个具体元素？（说不出 = 复盘没到位）
- [ ] 复盘结论是否已回流（选题库/方法更新/公开内容）？
- [ ] 季度校准是否已安排进日历？
