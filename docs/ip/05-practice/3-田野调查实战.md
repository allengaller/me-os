# 05-3 田野调查实战：约访 · 访谈 · 拍摄 · 剪辑

> 本节是田野调查方法的「现场版」——把方法翻成可照做的动作与话术。
> 每期田野项目开工前，把本节与 [03-methods/3-田野调查方法](../03-methods/3-田野调查方法.md) 一起过一遍。

---

## 1. 约访（邀约话术库）

### 1.1 标准邀约（微信/私信，可直接改）

> 「你好，我是曹亚仑，在做一档记录行业真实情况的视频（不是在采访你，也不是打广告）。
> 想跟你聊聊你工作的真实日常——收入、时间、遭遇，外界很多说法都失真，
> 我想把一线真实的声音带出去。
> 60 分钟左右，出镜方式你说了算（露脸 / 声音 / 只文字都可以），
> 涉及你的内容发布前一定先给你过目。会有一份小谢意，也欢迎你随时撤回。
> 方便的话，明后天哪个时间能聊 20 分钟认识一下？」

### 1.2 三种常见拒绝与回应

| 拒绝 | 回应 |
|---|---|
| 「不想露脸」 | 「可以不露脸：只出声音、只出文字稿，或者背影+变声都行」 |
| 「怕单位知道」 | 「署名匿名二选一由你定；地名单位名全部打码；撤回权书面给你」 |
| 「没时间」 | 「可以分两次 30 分钟；或者我跟你上一天班，边走边聊不额外占用你时间」 |

### 1.3 进场（蹲点/现场观察场景）
- 先买对方一杯水/一份早餐表达尊重，再说明来意；
- 观察优先于提问：先看 30 分钟再开口；
- 生意高峰期绝不打扰——约低谷时段（下午 2-4 点常见）。

## 2. 访谈（现场实战）

### 2.1 开场（0-5 分钟，信任建设）
1. 寒暄 + 自报来历（「我是做真实记录内容的，不是官方媒体」）；
2. **同意清单当场口头过一遍**（用途/范围/匿名权/撤回权/酬谢）；
3. 强调「你说了算」——受访者的控制感 = 素材的放开度。

### 2.2 结构（60-90 分钟，见方法篇 §4）
节奏心法：**事实先行（数字）→ 感受跟进（故事）→ 反直觉落点（误解）→ 方法收尾（可照做）**。
- 事实层问题清单：
  - 「你入行几年？怎么进来的？」
  - 「上个月收入多少？怎么构成的（列明细）？」
  - 「一天的时间账：几点起、几单、几小时、怎么休息？」
  - 「这个行业 10 个人里几个能留下来？」
- 感受层：
  - 「最近一次最想离职/放弃是什么时候？发生了什么？」
  - 「最被冤枉的一次？」
  - 「这件事做了三年，你最后悔/最骄傲的是什么？」
- 反直觉层（打脸点挖掘）：
  - 「外界对你们这行最大的误解是什么？」
  - 「网上说的 X（具体到说法），你遇到过吗？情况一样吗？」
- 方法层：
  - 「如果让你重来，你会怎么入行/避坑？」
  - 「给想进这行的新人三条最实在的建议？」

### 2.3 追问三件套（拒绝概括）
1. 「具体是？」——逼出细节（哪天/哪个单/多少钱）；
2. 「然后呢？」——逼出过程（不打断叙事）；
3. 「跟谁验证过？」——逼出证据链（交叉验证的入口）。

### 2.4 禁做清单
- ❌ 诱导：把「你觉得 X 对吗」换成「你的实际经历是什么」；
- ❌ 抢话与填充沉默（沉默 5 秒往往等来真话）；
- ❌ 把受访者的话当场「升华」再复述（「所以你的意思是……」→ 直接记原话）；
- ❌ 承诺无法兑现的报酬/传播承诺。

## 3. 拍摄（现场技术）

### 3.1 设备基线（零启动期）
- 手机（4K/1080P 60fps）+ 领夹麦（收音 > 画质）；
- 备用：充电宝 ×2、便携补光灯（可不用）、三脚架/手持云台（可选）。

### 3.2 拍摄清单（每场必拍）
```
□ 环境空镜（门店/工位/街景 ×5 段）
□ 工作过程（手部/动作细节，远中近三景别）
□ 采访主镜头（稳定、横拍、受访者看镜头或斜视均可）
□ 声音测试（30 秒试录回放确认）
□ 背景中第三方人/招牌/车牌检查（需打码或裁剪）
□ 结束彩蛋（受访者放松时的自然瞬间——经常是金句）
```

### 3.3 现场纪律
- 一镜到底优先（少停机，保语境的连续性）；
- 手机飞行模式（防来电打断）；
- 每段素材按「日期_受访者_内容」命名，当场备份一次。

## 4. 整理与剪辑

### 4.1 素材整理（发布前必经）
1. 逐字稿（原话不改写；语气标注：笑/沉默/停顿）；
2. 时间码索引（金句/反直觉点/数据点标记）；
3. 数据核验表（每个数字 → 来源 → 状态：已验证/估计值/待确认）；
4. 上下文档案（每段引用的前后语保留，防断章取义）。

### 4.2 剪辑的调性检查
- 保留环境音与呼吸感（拒绝「播音腔 + 背景音乐盖过原声」）；
- 原话上屏（可核对性原则）；
- 反馈与观点分离标注（受访者原话 vs 我的观察 vs 数据）；
- 节奏：剪掉的是「废话」，不是「语境的褶皱」。

### 4.3 发布前 48 小时回访
- 把涉及受访者的片段打包发去确认（文字 + 时间码）；
- 确认项：出镜范围 / 署名匿名 / 撤回意愿；
- 记录留档（截图保存为同意凭证）。

## 5. 收尾（每期固定动作）

| 动作 | 说明 |
|---|---|
| 感谢与回馈 | 按约定送酬谢；发布后把链接与观众反馈发给对方 |
| 关系维护 | 进入受访者库（联系方式/画像/可复访性）——长期田野资产 |
| 复盘 | 本期的 3 条改进入 reviewNote（约访/访谈/拍摄各自一条） |
| 素材归档 | 原片/逐字稿/同意记录/发布链接，目录化保存 |
