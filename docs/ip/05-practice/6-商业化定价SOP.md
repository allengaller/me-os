# 05-6 商业化定价 SOP：订阅哲学 × 实操流程

> 一句话：**定价不是「要多少钱」，而是「替自己选择客户、为承诺定刻度」——
> 每一次报价都在回答同一个问题：客户明年今天，还愿意为这个价格续费吗？**
>
> 本文档把「定价」这一件事从想清楚到收钱、再到复盘，做成可照着执行的流程。
> 理论依据见 [01-logic/4-商业与变现逻辑.md](../01-logic/4-商业与变现逻辑.md)：
> 定价哲学（§3.5）· 商业决策四问（§3.7）· 报价谈判（§4.2）· 订阅哲学（§6.3）。
> 使用时机：任何一次新品定价、商单报价、涨价、续费规则调整之前。

---

## 0. 全流程速览

```
定价前置检查（10 分钟，不过关先不要报价）
      ↓
五步定价法（价值盘点 → 锚点 → 阶梯 → 三问测试 → 首期验证）
      ↓
订阅/会员 → 走 C 订阅专项   商单 → 走 D 商单六步
      ↓
定价决策记录表（E）——每次定价都留档，供三个月后复盘
```

---

## A. 定价前置检查（每次必做，10 分钟）

### A1. 定位四问（§3.3 精简版）

1. 对谁最值钱？（谁愿意付费、付得起费）
2. 你被什么认可？（被记住的标签解决了谁的什么问题）
3. 你愿意收谁的钱？（不想服务的人，别设计进产品线）
4. 为什么是你？（换掉你之后，谁还能答得一样好）

> 四问答案写不满三行的定价，先别定。**定价之前先定人。**

### A2. 商业决策四问（§3.7）

1. 这笔钱会在任何层面伤害信任吗？
2. 我接得下且交付得起吗？（产能、质量、售后）
3. 它可重复吗？
4. 它会让我更「是」我还是更「不是」我？

> 任何一问答「否」→ 拒绝或重新设计，不硬上。

### A3. 订阅哲学三问（§6.3 落地为可执行检查）

| 哲学 | 检查问题 | 不过关的信号 |
|---|---|---|
| 利益对齐 | 这笔钱来自「让买家变得更好」，还是「让第三方更爽」？ | 需要话术硬推才能成交 |
| 名单所有权 | 成交后买家会沉淀到我自己的触点（公众号/企微/社群）吗？ | 成交即失联，复购靠平台推送 |
| 续订率是镜子 | 这个定价结构，客户明年今天会自愿续费吗？ | 定价里没有「明年继续的理由」 |

> 三条全过才进入 B；有一条不过，回到产品设计而不是改价格。

## B. 五步定价法（每个产品按序走一遍）

### Step 1 价值盘点（半小时）

| 对方获得的价值 | 可量化证据（数字/案例） | 只有你能给的（独特性） |
|---|---|---|
| 省下的时间/避免的损失/多赚的钱/更好的状态 | 用对方语言写：如「省 5 小时/周」「避开 3 个坑」 | 一手田野？体系方法？人格背书？ |

产出：一段 3 句话的「价值主张」，定价锚点全部从这里出。

### Step 2 找锚点（1 小时）

| 锚点 | 是谁 | 价格 | 交付内容 | 我们比它强在哪/弱在哪 |
|---|---|---|---|---|
| A（行业最低价） | | | | |
| B（直接对标） | | | | |
| C（高价天花板） | | | | |

判断：你的价值主张 ≈ B 或高于 B → 定价贴着 B 上沿；只有 C 级独特交付 → 才有理由向 C 看齐。**锚点是参照系，不是天花板。**

### Step 3 定阶梯（§3.2 产品阶梯落地）

| 档 | 给谁 | 价格 | 交付什么 | 这档验证什么 |
|---|---|---|---|---|
| L2 引流品 | 首购破冰者 | 99~999 | 小课/工具/单次诊断 | 需求真实性 |
| L3 主产品 | 认真要改变的人 | 999~9999 | 训练营/系统课/年社群 | 交付口碑 |
| L4 高客单 | 行动派/企业 | 1万+ | 顾问/闭门会/内训 | 背书与利润 |

规则：
- 各档价差建议 1:3~1:5（L2 199 → L3 999 → L4 3999 这类）；价差 <2 倍会互相抢客户；
- 每档写清「给谁」，写不清就删档；
- **定价是筛选器**：档位之间的缝隙里，站着你不想要的人。

### Step 4 三问测试（发布前，30 分钟）

1. **对朋友复述**：敢不敢把这个价格和交付，完整告诉一个挑剔的朋友？
2. **1:10 价值检验**：买家获得的真实价值，有没有达到价格 10 倍？（达不到说明定价超过价值，或价值没讲清）
3. **涨价 30% 谁留下**：涨价 30% 后，留下来的那批人是谁？（他们就是你的目标客户画像）

### Step 5 首期小步验证（发布后两周）

| 信号 | 收集方式 | 解读 |
|---|---|---|
| 「有点贵」 | 咨询记录/评论区 | 锚点没立住或价值没讲清 → 改 Step 1-2 |
| 「太便宜了」 | 已购用户反馈 | 阶梯缺 L4 → 补高客单档 |
| 「没感觉」 | 转化率 < 预期 | 不是价格问题，是需求/信任问题 → 回内容 |

> 首期只放 10~30 个名额或有期次，**小步验证不搞大促**——打折解决不了价值没讲清的问题。

## C. 订阅/会员定价专项（§6.3 落地）

### C1 周期决策

| 周期 | 适合 | 锚定技巧 |
|---|---|---|
| 月付 | 内容型轻订阅 | 价格是年费的 1/8~1/10，凸显年费划算 |
| 季付 | 训练型/进阶型 | 中间档，给「犹豫者」一个折中选项 |
| 年付 | 信任型/沉淀型 | 主推档；常配赠 1~2 个月形成「立刻看到优惠」 |

### C2 三档订阅结构（参考）

| 档 | 权益 | 价格 | 续费理由（每次续费时提醒什么） |
|---|---|---|---|
| 免费层 | 部分内容/公开内容 | 0 | 为付费层展示「值得」的证据 |
| 付费层 | 每周专属更新 + 社群 | 年费锚点价 | 新内容在持续发生（续订理由 =「还没完」） |
| 支持者层 | 额外直播/答疑/协助 | 1.5~2×付费层 | 「与这个人更近」的亲密度 |

### C3 底线规则（续订率的前提是信任）

- 自动续费默认**透明**：扣费前提醒、退订路径一屏可见；
- 退出条款写在购买页（不是小字）；
- 绝不「默认续费 + 高额违约金」——续订率是挣来的，不是锁来的。

### C4 涨价 SOP（六步）

1. 提前 ≥30 天公告涨价决定与生效日；
2. 老订户锁价 3~6 个月（或终身价迁移到新档）；
3. 公告里写明涨价换来的**新增价值**（不是成本上涨）；
4. 分批执行（新客先新价，老客到期再切）；
5. 记录流失量与留言（这是最诚实的定价反馈）；
6. 三个月后复盘：流失 >20% → 新增价值没兑现，检讨交付而不是回调价格。

### C5 每月检查（镜子逻辑）

> 月度续订率 < 70% → **暂停所有转化动作，回到内容质量**：不是价格错了，是「值得感」断了。

## D. 商单报价六步（§4.2 执行版）

1. **情报先行**：先让对方说预算与目标（锚定他的盘子），不先报价；
2. **报两档**：权益包 A/B，价格谈判变成方案选择；
3. **锚定高值**：先报最高档，降档也要守住底线（底线 = 你心里最低可接受价）；
4. **打包不降价**：要折扣 → 给权益（加转发/加话题/加一条），不给单价；
5. **合同十项核对**（§4.2 清单：交付物/排他/窗口/素材权/数据/KPI/付款节点/暴雷解约/违约上限/报备责任/税务）；
6. **成交后留档**：记录报价、还价过程与结果，三个月后回来算「报价命中率」和「商单口碑」（互动率 vs 内容均值）。

报价公式回顾（§4.2）：`报价 ≈ 触达价值（粉丝 × 垂类单价）× 调性系数 × 转化溢价 × 稀缺系数`

---

## E. 定价决策记录表（每次定价/调价一填）

| 日期 | 产品 | 档位 | 最终价格 | 锚点依据 | 三问测试结果 | 首期验证（两周） | 调整动作 | 三个月复盘日期 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

> 规则：**没有记录的定价等于没思考**；每次调价都从记录表回看上一版的判断错在哪。

---

## F. 一张页检查清单（每次报价前打印）

- [ ] 定位四问、决策四问、订阅哲学三问全过
- [ ] 价值主张能用 3 句话讲清（Step 1 产出）
- [ ] 有明确锚点（Step 2），不是拍脑袋
- [ ] 阶梯完整、各档「给谁」写清（Step 3）
- [ ] 三问测试通过（Step 4）
- [ ] 涨价走 C4 六步、续订率按月检查（C5）
- [ ] 商单走 D 六步且合同十项核对完
- [ ] 决策已记入 E 表

---

> 收束：价格是承诺的刻度，不是能力的刻度。
> 客户续的是「值得」，不是「便宜」的意外——**每一次报价，都是在为三年后的自己定价。**
