# 05-7 月度商业复盘模板：12 条路径 × 数据仪表盘

> 一句话：**复盘不是查账，是找「下个月唯一要改的一件事」——
> 先看结构（12 路径收入），再看漏斗（哪一级最差），最后查信任（有没有为钱伤身）。**
>
> 用法：每月最后一天或次月第 1 天，30 分钟填完；每季末（1/4/7/10 月）加做第 7 项。
> 指标口径与健康参考：[4-商业与变现逻辑.md §4.4](../01-logic/4-商业与变现逻辑.md)

## 附录：指标口径与取数位置

| 指标 | 口径 | 数据从哪取 |
|---|---|---|
| 粉丝净值 | 新增 − 取关（跨平台） | 各平台后台粉丝页 |
| 内容→转化率 | 付费数 / 曝光或阅读 | 各平台后台 / 成交工具后台 |
| 加微率 | 新增私域 / 阅读量 | 企微/个微新增记录 ÷ 内容阅读 |
| 客单价 | 收入 / 订单数 | 成交工具（小鹅通/星球/店铺） |
| LTV | 单客户累计贡献 | 客户台账（建议维护一份简单表格） |
| 退款率 | 退款 / 订单 | 成交工具后台 |
| 商单口碑 | 商单互动率 vs 内容均值 | 各平台后台对比 |
| 续订率 | 续订数 / 到期应续订数 | 订阅平台后台 |

> 工具会变，口径不变：**凡是要填数字的地方，都写它从哪来的，下个月才复得了盘。**
