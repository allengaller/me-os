# 06-1 定位与差异化流派：心智、垄断与紫牛

> 世界观：**观众的心智容量极小，只会为你留一个词的位置。
> 定位不是自我描述，是「被记成什么」的设计工程。**
> 代表：Ries & Trout / Seth Godin / David Perell / April Dunford

---

## 1. 核心思维逻辑（六条）

### L1 心智阶梯：争的不是产品，是「第一联想」
- **人物**：Al Ries & Jack Trout（《Positioning: The Battle for Your Mind》）
- **逻辑**：品牌竞争的战场不在市场，在用户心智；心智给每类事物只留 1-3 个位置。
  进不了前三，就等于不存在；「第一」进去的，最难被替换。
- **对 IP 的推论**：所有动作都服务于一个目标——当目标受众产生某个需求时，
  你的名字是第一联想。定位陈述就是这份「联想合同」。

### L2 存在的前提是可见：紫牛（Purple Cow）
- **人物**：Seth Godin（《Purple Cow》《This Is Marketing》）
- **逻辑**：「普通就是不可见」。广告与之前的营销方式失效后，
  被谈论的唯一方式是**值得被谈论**——像田野里的一头紫牛一样扎眼。
- **对 IP 的推论**：平庸内容不是零分，是负分（它们消耗观众的注意力预算，
  也让你的名字永远无法成为联想）。

### L3 个人垄断：你的组合无人能复制
- **人物**：David Perell（"Build a Personal Monopoly"）
- **逻辑**：别在拥挤赛道里争第一，去建立只有你能提供的组合：
  **独特经历 × 独特能力 × 真实需求**。垄断不是抢来的，是「你独有的交集」。
- **对 IP 的推论**：本 IP 的垄断区 = 「走进各行业现场的极致工程师」——
  访谈博主没有工程方法，工程博主没有现场经历，组合交集只此一份。

### L4 竞争不是同行，是替代选择
- **人物**：April Dunford（《Obviously Awesome》）
- **逻辑**：定位必须先回答「观众不看我的时候会看什么」——替代选择
  （书、课程、其他博主）上的差异化才有意义；比同行强没用，比替代物有用才行。
- **对 IP 的推论**：本 IP 的替代物是「成长课程/纪录片/测评号」，
  它们给不了「一手反馈 × 可照做系统 × 本人下场」——这就是差异化的定义域。

### L5 定位是约束，约束产生一致性
- **人物**：Seth Godin / 品牌战略惯例
- **逻辑**：什么都做 = 什么都没做。定位的本质是「明确拒绝什么」——
  拒绝换来的是清晰的心智标签与可重复的供给模式。
- **对 IP 的推论**：明确不服务「速成爽感人群」，不供应「情绪价值」——
  拒绝清单本身就是定位的一部分（本 IP 已写入品牌蓝本 §3.3）。

### L6 说人话：定位要能被复述
- **人物**：Seth Godin（"If you can't say it simply, you don't understand it"）
- **逻辑**：一个定位如果不能被一个普通人一句话复述给朋友，它就没有进入心智。
- **对 IP 的推论**：测试方式——让朋友看完简介后复述：「他是干嘛的？」
  复述出来的是「田野调查的极致工程师」，定位就成立了。

## 3. 批判与警戒（不学什么）

| 危险形态 | 问题 | 警戒 |
|---|---|---|
| 定位迷信 | 一劳永逸、拒绝进化 | 定位需季度校准（03-方法/1 §6.2） |
| 自嗨定位 | 只有自我认同，观众无感 | 复述测试：让第三个人说一遍 |
| 伪差异化 | 差异只在话术里，不在产品里 | 落到「观众可感知的证据」 |
| 过度窄化 | 窄到没有内容可做 | 窄在「价值供给」，不窄在「选题边界」 |
| 竞争拟人化 | 天天盯同行 | 替代选择才是坐标系（L4） |

## 4. 迁移到本 IP（已采纳/待试点）

| 机制 | 本 IP 的落地 |
|---|---|
| 心智一个词 | 主词「田野调查」（副：「极致工程」），所有标题/简介围绕它 |
| 一词复述测试 | 季度校准仪式：让 3 个朋友复述「他是干嘛的」 |
| 紫牛可见性 | 选题四问加一问：「这条内容值得被谈论吗？」 |
| 垄断交集 | 定期盘点：我的独特经历/能力/需求交集是否在扩大 |
| 替代选择矩阵 | 每次内容立项对照「书/课程/纪录片」缺什么（已入 03-方法/1 §5.2） |

**验证方式**：季度校准（03-methods/1）中检查——被复述率、被谈论率、
「提到真实行业反馈第一个想到我」的联想测试。
