# 04-1 第一性思维：拆到本质再重建

> 一句话：**类比让你快速开始，但只有第一性让你正确地开始——
> 把问题拆到「事实 + 约束」，再从那里重建结论，剩下的都是惯性。**

---

## 1. 第一性 vs 类比的差别

| 维度 | 类比思维 | 第一性思维 |
|---|---|---|
| 快速 | 快（抄现成答案） | 慢（拆完才建） |
| 适用 | 变化小、已验证的场景 | 新场景、重要决策 |
| 失效点 | 前提不同时照搬（跨领域翻车） | 拆错层（拆得不够深） |
| 高效应 | 维持效率 | 突破认知 |

**判断依据**：重要决策（定位、选题、商业化、回应争议）用第一性；
日常执行（剪辑、写标题）用已固化的方法，不必每次重拆。

---

## 2. 拆解的完整步骤（四层）

```
第 1 层 现象    是什么在发生？（可观察的事实）
第 2 层 目标    我要达成的结果是什么？（不给目的就拆 = 原地打转）
第 3 层 事实    哪些是公认事实？（去验证，别假设）
第 4 层 约束    哪些是不可改变的？（物理、规则、人性、时间）
→ 重建：从「事实 + 约束」推出结论，标注「推断」与「已验证」
```

**示例：选题「为什么一线从业者不愿意接受采访？」**

| 层 | 内容 |
|---|---|
| 现象 | 邀约被拒率高，业内普遍说「没人愿意出镜」 |
| 目标 | 建立起可持续的田野受访意愿 |
| 事实 | 拒绝理由的真实分布（怕被老板知道？怕被同行笑话？怕麻烦？）——用 5 次拒绝对话验证 |
| 约束 | 隐私不可跨越；时间有限；信任需要时间与接触 |
| 重建 | 结论：拒绝的根因多半是「成本大于信任」→ 解法是降低对方成本（匿名/文字/署名权）+ 提高信任（先给价值、同意清单、回馈惯例）——而不是「多塞钱」或「死缠烂打」 |

## 3. 第一性在内容创作中的三个落点

1. **选题落点**：「大众直觉 vs 证据」的反差是天然选题——找出叙事里未经证实的一环。
2. **方法落点**：「为什么这条内容火？」别学形态（标题模板），拆机制
   （前 3 秒给承诺 → 降低流失；情绪共鸣 → 触发转发）。机制可迁移，形态不可。
3. **判断落点**：「数据为什么涨/跌？」按层拆：
   曝光（选题/封面）→ 完播（结构/节奏）→ 互动（观点/问题）→ 转粉（定位一致性）。
   拆到哪层，就只改哪层。

---

## 4. 拆到多深算够（停下来的标准）

- 出现「公认事实」（可查证、无争议的物理/规则）→ 够了；
- 出现「不可再拆的约束」（时间、成本、人性、法律）→ 够了；
- 出现「我们默认如此」而没有证据支撑 → **这里就是断层，继续拆**。

**常见拆不动的借口**：
「大家都这么做」→ 大家这么做 = 惯性，不是证据；
「行业惯例」→ 惯例 = 约束吗？查一下它当初为什么形成；
「我直觉觉得」→ 直觉 = 待验证的假设，标注清楚，别当结论。

---

## 5. 第一性 × 内容公式（产出格式）

拆解不能散点输出，按品牌蓝本的呈现顺序组织：

```
现场（已发生的事实）→ 引入矛盾（大众以为 vs 实际如何）
→ 拆解（事实 + 约束逐条摆）→ 结论（对应证据，标推断）→ 落地（观众能照做）
```

示范句式：
> 「先说结论：网传的『骑手月入过万』，拆到单量×单价−成本之后，
> 只有少部分时段成立。判断依据是这三个数（来源：52 个样本）——
> 其余部分是我的推断，欢迎打工人们进评论区指正。」

## 6. 自检清单

- [ ] 我的结论是从「事实 + 约束」推出的，还是「因为别人都这么说」？
- [ ] 每个关键数字是否可指向来源（或明标估计值）？
- [ ] 我是否分清了「已验证」与「推断」？
- [ ] 最近有没有一个「行业常识」值得被我用同样方法拆一遍？
- [ ] 拆解输出是否符合「现场→矛盾→拆→结论→落地」？
