# 04-5 风险与边界思维：预案先行

> 一句话：**公共表达的每个风险都可以提前设计——比「出事再补救」便宜一个数量级。
> 本节把风险分成四类，每类给出「预防 + 应对」的组合预案。**

---

## 1. 风险全景（四类）

```
┌──────────────────────────────────────────────────────────┐
│  A 争议类   题材争议 / 立场冲突 / 价值观翻车              │
│  B 信任类   断章取义 / 数据被质疑 / 事实错误              │
│  C 隐私类   受访者反悔 / 个人信息泄露 / 未成年人          │
│  D 运营类   平台限流封号 / 盗用抄袭 / 恶意攻击            │
└──────────────────────────────────────────────────────────┘
```

原则：**预防成本 < 应对成本 < 公关成本**。能设计掉的别等发生。

---

## 2. A 类：争议题材

**预防**：
- 争议题材立项额外过一道「平衡关」：是否包含多方反馈、完整上下文？
  立场是否可被追溯为证据而非情绪？
- 发布前用第一性自问：结论的每一环都有证据链吗？

**应对**（品牌蓝本 §8.6）：
- 被质疑立场 → 给相关方回应机会，不删帖回避（删帖 = 认领「心虚」）；
- 被断章取义 → 公开完整素材与上下文（素材库是弹药库，前期存档纪律决定战斗能力）；
- 升级（被网暴/法律威胁）→ 停止公开争辩，走事实澄清 + 必要时法律途径；所有沟通留档。

---

## 3. B 类：信任事故（数据/事实）

**预防**：
- 发布前数据三查：来源、可复核性、标注（估计值必须标）；
- 绝对化断言词表扫描（最强/没有之一/必看/震惊）；
- 关键声明留原始记录（截图、录音、日志）。

**应对**——更正 SOP（24 小时窗口）：
```
收到质疑 → 致谢 + 说明核实计划（不发「我没错」）
核实（假定对方有部分道理）→ 拿到结论
确实错了 → 正文修正 + 各平台发布更正说明 + 记入复盘
无法证实 → 明确标注「此说法暂无法证实」，降级为观点
```

**延误代价参考**：错误存在的每一天都在扣信任利息，24 小时是最佳窗口，
72 小时后每多一天，更正效果衰减一成（近似经验值，方向可复核）。

---

## 4. C 类：隐私与受访者权益

**预防**：
- 同意清单前置（见 [03-methods/3-田野调查方法](../03-methods/3-田野调查方法.md) §5）；
- 拍摄现场确认「背景中路人/招牌/车牌」——涉及第三方的一律模糊或剪掉；
- 数据脱敏：收入、地点、可识别细节按受访者要求处理。

**应对**：
- 受访者反悔 → **无条件撤下**（哪怕素材再精彩）——记录到复盘，检讨采集环节；
- 隐私泄露（我方过错）→ 立即下架 + 公开致歉 + 删除所有副本；
- 未成年人 → 监护人知情同意书留档；拿不准年龄 = 不拍。

**底线**：任何一次隐私事故，都按下架 + 致歉 + 流程修订三步走，不谈判。

---

## 5. D 类：运营风险

| 风险 | 预防 | 应对 |
|---|---|---|
| 平台限流/封号 | 多平台矩阵 + 私域沉淀（不要把鸡蛋放一个篮子） | 主阵地临时切换；发公告告知订阅者 |
| 内容盗用/抄袭 | 保留创作原件（工程文件、时间戳）；平台原创声明 | 原创声明申诉；公开澄清（不吵架）；涉及商业 → 法务 |
| 恶意攻击/诋毁 | 提前写好「不参战边界」（只回应事实，不回应人格） | 按 A 类处理：事实澄清 + 上下文；情绪攻击不接 |
| 账号被盗 | 强密码 + 二步验证；提权操作双人确认 | 立即冻结 + 公告说明 + 恢复验证 |

**数据安全**：所有素材（录音/照片/文稿）双备份（本地 + 云端），
受访者同意记录单独归档——它们是信任资产的保险单。

## 6. 风险预案表（更新节奏：每季度检查一次）

```
┌────────────────┬────────────┬────────────┬────────────┐
│ 风险 │ 概率 │ 危害 │ 预防措施（已有的勾上） │ 应对人/时限 │
├────────────────┼────────────┼────────────┼────────────┤
│ 行业争议 │ 中 │ 高 │ 平衡关/证据链 │ 24h 内澄清 │
│ 断章取义 │ 高 │ 中 │ 素材存档 │ 48h 内公开素材 │
│ 数据质疑 │ 中 │ 高 │ 三查 + 标注 │ 24h 更正 SOP │
│ 受访者反悔 │ 中 │ 高 │ 同意清单 │ 立即下架 │
│ 平台封号 │ 低 │ 高 │ 矩阵 + 私域 │ 切换+公告 │
│ 账号被盗 │ 低 │ 高 │ 2FA │ 冻结+恢复 │
└────────────────┴────────────┴────────────┴────────────┘
```
