# 04 思路 —— 个人 IP 的决策与思维框架

> 方法告诉你怎么做，思路告诉你在岔路上怎么选。
> 本层是一套**可内化的判断力系统**：第一性思维（拆解一切）、系统与飞轮思维
> （看清结构）、决策与筛选思维（减少错误）、批判与反直觉思维（对抗幻觉）、
> 风险与边界思维（守住底线）。

---

## 1. 五套思维全景

```
┌────────────────────────────────────────────────────────────┐
│  1. 第一性思维    拆到事实与约束，再从本质重建（一切的地基） │
│  2. 系统与飞轮    看到环与反馈，而不是单点与事件            │
│  3. 决策与筛选    用四问与优先级矩阵减少错误决策            │
│  4. 批判与反直觉  证伪自己、识别幻觉、把打脸变成内容        │
│  5. 风险与边界    争议、断章取义、隐私——提前有预案         │
└────────────────────────────────────────────────────────────┘
```

| 思维 | 典型场景 |
|---|---|
| 第一性 | 「这个选题值不值得做？」「这个方法为什么有效？」 |
| 系统/飞轮 | 「为什么最近数据一直平？」「我该先补哪个环节？」 |
| 决策/筛选 | 「这个热点蹭不蹭？」「这条内容发不发？」 |
| 批判/反直觉 | 「我的结论会不会是错觉？」「大众叙事哪里可疑？」 |
| 风险/边界 | 「被断章取义怎么办？」「受访者反悔了怎么办？」 |

## 3. 思路的基本用法：三问决策

遇到任何「拿不准」（选题、合作、回应、爆发）：

```
① 事实是什么？（先分离情绪与事实，摆出证据）
② 这在我的系统（飞轮）里是什么位置？（一环还是噪声？）
③ 哪条信念/边界被触碰了吗？（哲学层否决优先）
```

三问之后仍拿不定 → 用 04-3 的决策矩阵；仍卡住 → 写入「待验证清单」，不急着发。
