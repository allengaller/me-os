## 2. 核心结论（速览版）

1. **IP = 信任 × 时间 × 复利**。内容只是表现形式，真正积累的是「被记住 + 被信任」。
2. **定位是减法不是加法**。宁可让 1 万人记住你「是干田野调查的极致工程师」，不要让 100 万人不知道你干嘛的。
3. **真实性是唯一无法被抄袭的差异化**。越包装越同质化；越真实越无人可复制。
4. **先供给，后收获**。商业化的正确次序是：影响力 → 信任 → 供给价值 → 自然变现；顺序乱了就崩。
5. **系统大于灵感**。选题漏斗、内容支柱、一鱼多吃、复盘节奏——把创作变成流水线，把流水线变成资产。
6. **每一条内容都要通过一致性检查**：署名换成别人是否成立？不成立就不发。
