## 文档分工（与品牌执行层）

本目录是「通用方法论层」；品牌侧另有「执行层」文档（并行维护），职责划分如下：

| 文档 | 角色 | 内容 |
|---|---|---|
| `docs/self-media/`（本目录） | 方法论层 | 为什么 + 方法 + 平台参考线；不绑定账号 |
| `docs/brand/OPERATIONS.md` | 品牌执行手册 | 每日操作标准、模板（数据周报/月报、单期复盘、账号矩阵）、AI 自动化 |
| `docs/brand/BUSINESS.md` | 一人公司经营层 | 商业模式、产品梯度、财务法务、风险登记 |
| `docs/EPISODE_PIPELINE.md`、`docs/FIELD_LOG_*.md` | 田野执行现场 | 选题管线、分镜表、受访授权文本 |

分工铁律：

1. **模板与表单归属执行层**（周报/复盘/矩阵/分镜），本目录不重复造
2. **方法论与参考线归属本目录**；执行层引用本目录数字，冲突时以更新日期新者为准并回写
3. **实际记录以品牌控制台 / 执行手册为准**（支柱、账号矩阵等），本目录只维护示例映射
4. 执行层尚未补齐的模板（如内容日历）不在本目录新建，待执行层补齐后引用

## 一页读法（冷启动路径）

1. 读 `01` §2 对照自己所在的阶段（先定阶段，再谈打法）
2. 读 `01` §3 建立内容流水线（固定节奏优先）
3. 按 `01` §9 选定主战场，精读 `02` 对应章节
4. 每周用 `03` §7 复盘模板 + §10 自检收尾

## 维护约定

- 平台算法与政策变化 → 更新 `02` 对应章节，顶部日期标注（数据参考线只作参考，以自家账号同平台数据为基准）
- **每半年（1 月 / 7 月）校准数据参考线**：对照各平台官方「规则中心 / 创作者学院」最新口径更新 `02` 各章，与 `01 §6.4` 数据校准环节联动
- **BrandPillar 定稿后回填 `01 §9.2` 支柱映射**（现状为示例，见该节回填约定）
- 实验验证有效的新方法 → 补入 `03`（按 §10.2 每周弹药节奏）
- 本品牌定位/支柱调整 → 先改 docs/BRAND.md，再同步 `01` §9 映射
- 所有数据口径以「同平台自比、周环比」为原则，禁止跨平台攀比
