# SELF-MEDIA — 自媒体实战知识体系

> 一句话：把自媒体当一门生意经营 —— 定位、生产、分发、复盘的端到端打法 + 思维框架库。
> 与品牌板块的关系：本目录是「打法知识库」（怎么做），Brand Console 是「执行与管理台」（做了什么、数据如何）；内容支柱与渠道在两边对齐使用。

## 文档导览

| 文档 | 解决什么问题 | 什么时候读 |
|---|---|---|
| [01-实战总纲](./01-实战总纲.md) | 端到端作战手册：底层逻辑、四阶段作战地图、生产流水线 SOP、质量红线、指标体系、运营节奏、工具链 | 启动之前通读一遍；每季度复核阶段与节奏 |
| [02-分平台手册](./02-分平台手册.md) | 9 平台作战地图：画像、算法、规格、爆款规律、冷启动、数据健康线、商业化、雷区 | 选定主战场时精读对应章；新平台起号前必读 |

## 一页读法（冷启动路径）

1. 读 `01` §2 对照自己所在的阶段（先定阶段，再谈打法）
2. 读 `01` §3 建立内容流水线（固定节奏优先）
3. 按 `01` §9 选定主战场，精读 `02` 对应章节
4. 每周用 `03` §7 复盘模板 + §10 自检收尾

## 维护约定

- 平台算法与政策变化 → 更新 `02` 对应章节，顶部日期标注（数据参考线只作参考，以自家账号同平台数据为基准）
- 实验验证有效的新方法 → 补入 `03`（按 §10.2 每周弹药节奏）
- 本品牌定位/支柱调整 → 先改 docs/BRAND.md，再同步 `01` §9 映射
- 所有数据口径以「同平台自比、周环比」为原则，禁止跨平台攀比
