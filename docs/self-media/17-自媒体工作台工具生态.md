## 4. 组合参考（全开源个人创作者方案）

```
Obsidian/仓库 → Quartz（数字花园）或 ghostwriter（Markdown→Ghost，github.com/yinguobing/ghostwriter）
            → Ghost 主站（会员变现）
            → MultiPost / Wechatsync（多平台分发）
            → MoneyPrinterTurbo / VideoLingo（长文→短视频/二创）
            → TrendRadar（选题） + Huginn（数据复盘）
```

## 5. 风险与提醒

- **发布类 MCP 普遍依赖 Cookie/Selenium 登录**（小红书/抖音/公众号），有风控风险，适合低频自用，账号安全自负；
- **平台无官方数据 API**（小红书/抖音/公众号），开源「官方数据聚合看板」基本空白——主流做法是 Huginn+浏览器自动化，或人工录入复盘；me-os 的品牌快照连接器（bilibili/youtube/github/import）正好补位；
- **官方化趋势**（2025-2026）：小红书 Red Skill、飞书/讯飞/腾讯云/百度曦灵官方 MCP、WordPress/Canva 官方 MCP——非官方工具随时可能过期，选型时优先看「官方或活跃社区」；
- 部分项目已停更/归档（douyin-mcp-server、ShortGPT、wechat-publisher-mcp），接入前确认活跃度。
