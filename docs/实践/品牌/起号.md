# 账号级起号/增长作战手册（Account Launch & Growth Playbook）

> 定位：从 0 到 1 把账号做起来的作战手册——平台选择、账号落地、起号内容策略、数据指挥、增长引擎与投放原则。

## 1. 起号总原则

- **单点打透**：先只做一个主阵地（DESIGN §6.9），把一个内容类型做到爆，再复制、再扩平台。
- **内容资产 > 粉丝数**：起号期目标是攒「可复用的代表作」，粉丝是结果不是目标。
- **真实反馈驱动**：每 10 条内容至少 1 条直接来自观众反馈（反馈即田野，DESIGN §6.6）。
- **数据是唯一裁判**：不凭自我感觉评判内容，看完播/互动/关注转化率（§5）。
- **红线不变**：不买粉、不刷量、不互赞互关群（与 DESIGN §6/OPERATIONS §7 一致）。

## 2. 平台选择与账号落地

**主阵地决策因素**（候选：B站 / 视频号 / 抖音 / YouTube）：

| 因素 | 权重问题 |
|---|---|
| 内容形态 | 长视频（8–20 分钟田野）与平台生态是否匹配 |
| 目标受众 | 核心受众「系统型成长者」（DESIGN §3.1）是否活跃 |
| 创作者生态 | 同品类头部/腰部创作者密度与天花板 |
| 变现路径 | 平台对知识类内容的激励、商单与课程生态 |

**主阵地初判（预填分析，待拍板）**：

| 平台 | 长视频匹配 | 受众浓度 | 变现通路 | 初判 |
|---|---|---|---|---|
| B站 | 高（社区原生，弹幕互动） | 中高（知识区成熟） | 激励 + 课程友好 | **首选候选** |
| 视频号 | 中（微信生态分发） | 中（熟人社交转发） | 私域闭环 | 第二候选 |
| YouTube | 高 | 中（国际） | 广告 + 会员 | 国际延伸 |
| 抖音 | 低（时长导向） | 高（算法起量快） | 星图 + 直播 | 切片导流，非主阵地 |

拍板依据：回看 DESIGN §6.9 渠道角色 + 本节决策因素，月报数据滚动修正。

**账号落地四件套**（上线前完成，承接 DESIGN §0 档案取值）：

1. **昵称**：曹亚仑（本名直用，不搞花名）；
2. **简介**：一句话定位 + 更新承诺（模板：「基于极致工程的田野调查者。把各行各业真实反馈带进内容，所有输出都是我。每周更新。」——按所选平台改字数）；
3. **置顶 3 条**：代表作 1 + 方法论总览 1 + 「你最想让新观众看到」1；
4. **视觉**：头像/封面按视觉方向草案上线（DESIGN §7.2），先统一再迭代。

**主页转化率**（曝光→关注）是起号期第一指标：筛选题时把「是否自带关注理由」当一票否决项。

## 3. 起号期内容策略（前 30 条）

**内容配比**：70% 深耕主内容类型（田野/方法论）｜ 20% 强互动轻内容（自我调教日志）｜ 10% 实验新形式。

**前 3 条必做选题**（按序打磨，宁慢勿糙）：

1. **反直觉/争议题**（必须有真实证据支撑）——建立「敢说真话」认知；
2. **强实用题**（看完就能照做）——建立「可照做」认知；
3. **超预期人物题**（田野里挖到一个想不到的反馈）——建立「真实一手」认知。

**每条必带**：3 秒内钩子 + 明确的「交付」（观众看完能带走什么）。

**系列化**：第一条起就给内容挂系列名（如「田野实录·外卖行业」），为爆款复制留接口（§6）。

**选题卡模板**（立项时填写，作为 Console ContentItem 的前置草稿）：

| 字段 | 内容 |
|---|---|
| 标题候选 ×3 | 1. / 2. / 3. |
| 钩子（第一句，3 秒内） | |
| coreMessage（一句话） | |
| 支柱 / 类型 / 优先级 | （DESIGN §6.1 / §0 类型 / 高-中-低） |
| 田野对象（≥3 人或连续现场） | |
| 同意清单 | ☐ §8.5 六项已走完 |
| 一鱼多吃规划 | 长视频 / 切片 / 图文 / 短帖 / 摘要 |
| 预发布检查 | ☐ §9.4 六项；☐ 标题封面符合 §5.6 |

## 4. 更新节奏与产能

- **最小可行产能**：每周 1 条精品长视频 + 2 条轻内容（日志/切片）。
- **提前量**：内容库保持 2 周存量，防断更——断更对起号期伤害最大。
- **批产**：田野行程一次多录（半天访谈 2–3 人、双机位），一天集中产 2–3 条素材；一鱼多吃层层转化（DESIGN §6.4）。
- **产能红线**：不牺牲身体与真实性换更新频率（BUSINESS §7 风险缓解 + 调性锚点）。

## 5. 数据指挥室

**核心四指标**（每条内容发布后跟踪）：

| 指标 | 看什么 | 动作 |
|---|---|---|
| CTR（曝光→点击） | 标题/封面是否成立 | 低于中位 → 换备选标题（OPERATIONS §3） |
| 完播率 | 钩子与结构是否成立 | 前 3 秒重做或拆切片测试 |
| 互动率 | 是否引发想说的冲动 | 加提问位、置顶引导评论 |
| 关注转化率 | 主页与系列感是否成立 | 优化置顶/简介/系列化 |

**实验纪律**：每周只测 1 个变量（标题/封面/时长/钩子），变量混测等于没测。

**爆款复盘**：播放 > 自己均值 3 倍的内容，逐项拆解（选题→标题→结构→发布时间→平台推荐节点），提取可复制要素写进下一期脚本。

**数据回填**：周报/月报（OPERATIONS §4）→ 季度校准（BUSINESS §8），所有数字进 Console 快照。

## 6. 增长引擎

- **爆款复制**：爆款出现后 2 周内做同类选题第二期（继承播放红利与认知）。
- **系列与合集**：系列名固定，合集页承接长尾。
- **联动**：受访者发布后联动转发（这是田野的合理返还）；同行互访；高价值评论公开化（经同意，DESIGN §8.3）。
- **借势**：行业事件用第一性视角回应——必须过 DESIGN §6.6 筛选四问，不蹭无关联热点。
- **搜索流量**：标题含行业关键词，起号期捡长尾搜索（冷启动期的稳定来源）。
- **私域承接**：简介/置顶一条入口（DESIGN §6.10），把平台粉丝沉淀为私域反馈池。

## 7. 投放原则（可选，谨慎）

- **定位**：投放是「放大器 + 测试器」，不是流量来源本身。
- **规则**：先自然发布跑 24–48 小时看数据，只投已被验证的内容；不投冷启动内容。
- **预算**：投放预算 ≤ 当月收入固定比例（建议起步 ≤10%，随财务校准，见 BUSINESS §3/§4）。
- **口径**：投放数据与自然数据分开记录，月报标注「含投放」。
- **红线**：不买假数据、不买粉；投放只做两件事——测试内容、放大爆款。与「真实」调性不冲突的前提是数据口径透明（DESIGN §8）。

## 8. 账号安全与限流诊断

- **安全基线**：绑定邮箱/手机 + 2FA + 登录设备管理；素材 3-2-1 备份（OPERATIONS §9）。
- **限流自查清单**：原创度（一鱼多吃是否做成「改编」而非搬运）、违禁词、广告未报备、频繁删除重发、互粉互赞。
- **不养号**：不做低质互粉；新号正常更新即可。
- **被限流时**：保留数据截图 → 对照清单排查 → 属实问题立即下架更正（DESIGN §8.3）→ 必要时平台申诉。

## 9. 阶段里程碑（承接 DESIGN §9.5「0→1 启动」）

| 阶段 | 目标 | 验收 |
|---|---|---|
| 激活（第 1–2 周） | 账号四件套 + 首批 3 条上线 | 主页完整、3 条代表作可被检索 |
| 验证（第 1–2 月） | 找到 1 个可复制的内容类型 | ≥1 条播放远超均值；周更不断 |
| 加码（第 2–3 月） | 系列化 + 爆款复制 + 私域入口 | 单个系列 ≥3 期；自然涨粉趋势为正；私域有首批反馈 |

具体涨粉/播放数字按平台、品类动态校准，月报滚动修正，不设死目标。
