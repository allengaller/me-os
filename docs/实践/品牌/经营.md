# 一人公司经营手册（One Person Company Manual）

> 定位：把「极致工程」品牌沉淀为可持续的一人业务——商业模式、产品线、财务法务、资产安全与季度经营节奏。
> 品牌口径以 [DESIGN.md](./蓝本.md) 为准；每日运营细节见 [OPERATIONS.md](./运营.md)。
> 声明：本手册是方法论与模板，不构成税务/法律/投资建议；涉及合规决策时咨询专业人士。

## 1. 商业模式一页纸

**价值主张**：让想真实成长的人拿到「各行各业一手反馈 + 可照做的极致工程系统」（DESIGN §2.1）。

**收入三层结构**（先信任后变现，匹配受众旅程 DESIGN §3.4）：

| 层 | 形式 | 角色 |
|---|---|---|
| 流量层 | 平台激励/广告分成 | 验证信号，不是主要收入 |
| 信任层 | 商单（守 §8.4 红线）、知识付费（课程/训练营）、会员社群 | 中期主力 |
| 产品层 | 出版物、MeOS（订阅/买断）、模板工具包 | 长期壁垒 |
| 服务层（后期可选） | 咨询/陪跑/企业培训 | 高客单，谨慎扩容 |

**原则**：收入顺序 = 先内容与信任，再变现；任何一层都不做割韭菜（DESIGN §8.4）。

## 2. 产品梯度（Offer Ladder）

| 层 | 产品形态 | 目的 | 门槛 |
|---|---|---|---|
| 免费 | 内容、公开复盘、田野笔记 | 建立信任 | 流量可承接 |
| 引流品 | 模板/清单/田野素材合订 | 转私域/邮件列表 | 一页纸可交付 |
| 利润品 | 课程/训练营/会员 | 收入主力 | 有重复购买与口碑 |
| 资产品 | 出版物/MeOS/工具 | 竞争壁垒 | 需要持续维护 |

**一致性检查**（逐层必过）：真实反馈驱动、可退款、不饥饿营销、不承诺速成。

## 3. 定价与收入目标

- **定价方法**：成本 + 受众感知价值双参考；定价依据是真实价值，不是焦虑价值。
- **退款政策**：所有付费产品公开可退条款（七天无理由起，守住「真实」调性）。
- **收入倒推练习**（模板）：

```
月收入目标 10000
÷ 客单价 299  ≈ 34 单/月
÷ 转化率 2%   ≈ 1700 次「到店」（阅读/完播）
→ 反推需要的内容量（按历史完播换算成条数/月）
```

每个数字上线实测后回填（月报 §4 校准）。

## 4. 财务与税务清单（原则性）

- **记账**：收入/支出按渠道记录，每月对账；商单款到即记。
- **发票**：商单/课程开票流程提前确认（对公或平台代开）。
- **主体选择**：0 收入阶段个人即可；收入稳定后评估个体户/工作室/公司——咨询专业人士。
- **储备金**：目标 6 个月生活开销（一人公司现金流缓冲）。
- **免责声明**：以上非税务/法律建议。

## 6. 资产与安全（数字资产盘点）

| 资产 | 内容 | 安全措施 |
|---|---|---|
| 内容资产 | 主素材/成片/未发布素材 | 3-2-1 备份（本地双份 + 云一份） |
| 用户资产 | 粉丝、私域联系人、邮件列表 | 隐私合规（个人信息保护意识）；永不转卖 |
| 品牌资产 | 域名、handle、商标、授权文件 | 归档 + 续费/续展提醒 |
| 财务资产 | 记账表、合同、发票 | 加密备份 |
| 账号安全 | 所有平台账号 | 密码管理器 + 2FA + 恢复邮箱 |

## 7. 风险登记册（Risk Register）

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 平台限流/封号 | 中 | 高 | 多平台矩阵 + 私域沉淀 + 内容备份 |
| 受访者纠纷 | 低 | 中 | 授权书 + 同意清单 + 撤回机制（§8.2/§8.5） |
| 版权/素材诉讼 | 低 | 高 | 素材授权凭据库（§8.7） |
| 收入波动 | 中 | 高 | 三层收入结构 + 6 个月储备金 |
| 健康透支（burnout） | 中 | 高 | 极致工程身体调教 + 固定休息 + 内容产能上限 |
| 单一依赖（某平台/某爆款） | 中 | 中 | 资产独立于平台：私域 + 邮件 + 作品库 |

每季度更新概率/影响与缓解措施（§8 节奏）。

## 8. 季度经营节奏（OKR 模板）

**季度目标 3 个**：影响力 1 个（如北极星指标）+ 业务 1 个（如某产品收入）+ 资产 1 个（如某个作品库进度），每个目标配 3 条 KR（承接 DESIGN §9.5 阶段目标）。

**季度校准流程**：

1. 回看 DESIGN.md（定位/支柱/阶段里程碑有无偏移）；
2. 三个月报数据对照（OPERATIONS §4）；
3. 财务对账（§4 清单）；
4. 更新风险登记册（§7）；
5. 输出下一季度 3 个 OKR 与内容日历（DESIGN §6.9）。

## 9. 一人公司守则

- **系统大于个人**：同一件事做两次就固化为模板/SOP——本手册与 OPERATIONS.md 即为此而建。
- **资产先于收入**：内容/用户/产品资产的积累优先于短期变现。
- **自动化优先**：AI Agent 承担重复劳动，人做判断（守 DESIGN §8.8 披露）。
- **真实是护城河**：任何自动化、商业化都不得稀释真实反馈（品牌本质 DESIGN §1.2）。
- **克制扩张**：每加一个平台或产品，先问它是否服务核心受众旅程（DESIGN §3.4）。
