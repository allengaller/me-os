## 一、立项三道闸门

### 1.1 第一道：四问（硬门槛，任一不过直接淘汰，不进打分）

1. **场景**：有没有一件「手头工作」能破冰？（修剪/称菜/堆码——一开口就能聊的具体事）
2. **对象**：他/她在哪个环境里反复生活？（小区/市场/城中村/服务区）
3. **疑问**：大众对这个群体的误解或好奇是什么？切口必须是**反常识**，不是「真辛苦」
4. **FDE 接口**：有没有「经验 vs 数据/AI」的自然缝隙？（硬凑出来的科技对照不算）

有对象没场景 → 无镜头可破冰；有场景没疑问 → 内容平平；没接口 → 那就是别人的节目，不是这个频道的。

### 1.2 第二道：六维打分（1–5 分，满分 30）

| 维度 | 问的是什么 | 打 5 分长什么样 |
|---|---|---|
| **信息差** | 观众以为自己知道、其实不知道 | 一句切口能让人改口（「纸分九种，当天行情比菜价还灵」） |
| **可拍性** | 破冰动作 + 收音 + 场地 + 时段是否可控 | 白天、固定摊位、站着就能聊、不抢生意 |
| **情感纵深** | 不煽情也立得住 | 有具体的得失决策，不需要 BGM 催 |
| **共鸣面** | 多少人能把自己代入 | 交房租/被平台派单/等一个客户 |
| **FDE 接口** | 经验与 AI 的缝隙是否天然 | 他那套判断本身就是个待训练的模型 |
| **低风险** | 授权/合规/题材饱和（反向计分，**越高越安全**） | 无单位审批、无隐私第三方入镜、没人拍过 |

**阈值**：≥24 优先立项 ／ 20–23 备选池 ／ 15–19 回炉（换切口重投一次） ／ <15 丢弃。
分数是**蹲点前的预判**，不是结论。蹲点之后必须回填实际分，虚高过的选题在库里标注原因。

**一个已知的刻度陷阱**：六维等权，于是「离你家近、好开口、没风险」的选题天然占便宜——园丁 A1 拿 26 分，其中 可拍性 与 低风险 各 5 分，而真正决定成片上限的 信息差 与 共鸣面 只有 4 和 3。**容易拍 ≠ 值得拍。** 因此加一条硬规则：**信息差或共鸣面任一 ≤3 的条目，即使总分达线也不得优先立项，只能进「蹲点验证」**，用现场 30 分钟看它到底有没有真话可挖，再决定是否破格。

### 1.3 第三道：三判别题（终审，口头答得出才出门拍）

- 这条选题**「大众以为自己知道、其实不知道」**的那一句是什么？说不出来 → 回炉。
- 我手里有没有**别人拿不到的一手素材**？只有观点没有画面 → 回炉。
- 观众会不会**转发给一个人**？转给谁、说什么话？答不出 → 共鸣面打对折。

## 五、不入池（负筛，写死，省得每次重新吵）

| 题材 | 一句理由 |
|---|---|
| 残障/重病/流浪等困境群体 | 情绪红利过大，必然滑向消费苦难；这个频道输不起信任 |
| 殡葬、临终、器官相关 | 同上，且二次传播伤害不可逆 |
| 精神疾病、救助站、戒毒 | 需要机构与监护人授权，实际拿不到 |
| 未成年人单独出镜 | 不做 |
| 医生、护士、警察、教师等持证/在编岗位 | 触碰资质与单位口径；这是个人记录，不是新闻采访 |
| 非遗「传承困境」 | 已被拍烂，且叙事必然拔高，违背「不拔高不煽情」 |
