## 二、双栏目体系

### 2.1 栏目 A：FDE 田野日志（正片）

- **节奏**：每两周 1 期（田野采访耗时，宁缺毋滥）
- **栏目定位**：IP 主产品——一段完整的素人田野访谈
- **结构模板（七段固定动线）**：

```
1. 定场卡（3-5s）    黑屏白字打字机：曹亚仑 | 走出空调房，去泥土里找答案
2. 现场引入（15-30s） 边走边说，交代今天去哪、去见谁、为什么
3. 锁定目标（10s）    目标人物远远出现（背影/侧影，保留距离感）
4. 破冰 → 深谈（正片主体） 引子库四阶段推进，追问技巧机动使用
5. 尾节四问（40s）    每期同一段，对象对镜头。问法见《通用尾节四问.md》，勿在此复制
6. AI 工作流片段（20-40s） 采访后 24h 内：AI 转写方言 → AI 提炼金句 → 人工核对
7. 收尾留白（10-20s） 金句停在黑屏字卡 → 下一期预告
```

第 5 段是**跨期可比语料的唯一采集位**（M2「田野洞察」的实际来源），也是竖屏可独立成条的自足切片。三条前提：破冰与四阶段未走完不许跳到第 5 段；「AI」一词在 T1/T2 不由采访者出口；第 5 段不改变选题立项门槛。

### 2.2 栏目 B：田野工作流（支线）

- **节奏**：每周 1 期，30-90 秒短内容，纯竖屏
- **栏目定位**：人设放大器——立「FDE 工程师」身份、承接 Build in Public、为 To B 叙事（数据→洞察）铺路
- **内容主题池**（四类轮换）：

| 类型 | 示例选题 |
|------|----------|
| AI 工具实测 | 「AI 转写山东方言翻车现场」「AI 提炼脚本 vs 人工整理，快 10 倍」 |
| 装备逻辑 | 「为什么田野采访我只带这三样」「抗噪麦克风实测：菜市场收音对比」 |
| 方法论拆解 | 「破冰话术拆解：怎么让陌生人 30 秒开口」「追问技巧：沉默 3 秒的威力」 |
| 复盘 / 幕后 | 「这期采访被拒绝了 3 次」「素材作废复盘：我错在哪」 |

### 2.3 双栏协同

- 支线为大档引流（「完整版见田野日志 00X」），大档完成后支线发「幕后/复盘」——两栏互为钩子
- 编号统一：田野日志 001 / 田野工作流 001
- 节奏排期示例（两周一轮）：

```
W1 周四  工作流：工具实测
W2 周六  田野日志：正片
W2 下周三 工作流：幕后复盘（承接正片热度）
```

### 3.4 破冰话术决策树（怎么开口不像推销员）

**核心原则**：先不开镜头、不表白来意；用「观察 + 请教」从手头的事开口，聊开 2-3 轮后再提拍摄；被拒绝就把过程剪进成片（Build in Public）。

```
到达现场 → 观察：他手头在做什么（修剪/浇水/除草/换土）、状态（忙/闲）→ 选择对应开场

                                  ▼
        开场（只问手头事，不自我介绍，不递名片）
        ├─ 修剪：「叔叔，我看您剪这枝的时候停了一下，
        │         是舍不得剪，还是这枝有讲究？」
        ├─ 浇水：「叔叔，这叶子看着有点蔫，是水浇多了还是太阳太大？」
        └─ 除草/换土：「叔叔，这换下来的土颜色不一样，是加过什么吗？」
                                  │
                   ┌──────────────┴──────────────┐
                   ▼                              ▼
           有回应（进入聊天气）             被无视 / 简短拒绝
                   │                              │
                   ▼                              ▼
      第二句往「时间线」导：              退一步不纠缠：
      「您干这行多少年了？              「行，那您先忙。」
      这园子以前什么样？」               走开几步 → 换人/换时段再来
                   │                     （此段剪进成片做「尝试 #1 失败」）
                   ▼
      聊开 2-3 轮后，表白来意：
      「叔叔，其实我是做视频的，
       专门记录普通人的生活。
       刚才听您说话特别有意思，
       能不能让我录一段？您不愿意我绝对不录。」
                   │
       ┌───────────┴───────────┐
       ▼                       ▼
    同意 → 口头授权 + 开拍        拒绝 → 留一句「那以后有机会」+ 道谢离开
```

补充话术（深聊导引轮）：「您刚才说看云就知道下不下雨，那今年夏天这雨，算正常还是反常？」——承接 FDE 专属引子（经验 vs 数据）。

### 3.5 拍摄日 checklist

**前夜**
- [ ] 设备充电：手机 / 相机 / 领夹麦 / 备用录音设备
- [ ] 存储清理：手机+相机各留 ≥ 30 分钟容量
- [ ] 手机里存好授权文本（见 3.6）

**到场**
- [ ] 不打扰原则：目标在忙或心情不佳 → 不硬聊，先等或先踩点
- [ ] 按 3.4 决策树破冰 → 聊开 → 表白来意 → 口头授权
- [ ] 开拍前试麦（10 秒，回放确认收音）

**拍摄**
- [ ] 主镜头：手机/相机横屏固定（B站完整版素材）+ 竖屏构图同期保底（精华版素材）
- [ ] 每段开始前口头报段：「第 X 段」
- [ ] 空场 30 秒环境音（裁剪时垫底用）
- [ ] 受访者不想播的内容：当场确认「这段不播」，记在当场笔记

**收尾**
- [ ] 感谢 + 问「要不要看成品」，留联系方式（回访 + 后续授权用）
- [ ] 当天备份：录音/视频三处（本机 + 移动盘 + 云端），命名 `2026-09-XX-园丁-原声/转写/成片`
- [ ] 24h 内跑工作流（第八章）

**第一期最低设备配置**（不新增预算也能拍）：
手机（主摄）+ 百元级领夹麦（指向性，降环境噪）+ 手机自带录音做双保险。Pocket 4 系列（见调研文档第十一节）作为竖屏机位升级项，验证第一期数据后再决定买哪款。

### 3.6 受访授权流程（口头版）

1. 聊开后再提拍摄，说明用途（「发在抖音/B站，记录普通人的生活」）
2. 说清楚三点：会露脸 / 可以随时喊停 / 不想播的内容一定剪掉
3. 对方口头同意后用手机录一句「同意」存证（本地方便，不要求签字）
4. 留联系方式（给成片 + 事后可撤回）

## 四、视觉规范（VI）

### 4.1 黑屏字卡（定场卡/金句卡）

| 项 | 规范 |
|----|------|
| 背景 | 纯黑 #000000 |
| 字体 | 思源黑体 Bold（跨平台一致），禁用艺术字 |
| 字号 | 主字 ≈ 画面宽度 40-50%（1080P 基准），裁剪后仍可读 |
| 构图 | 居中，可轻微上移避开平台 UI 安全区 |
| 动画 | 定场卡 = 打字机逐字、时长拉满；金句卡 = 缓慢淡入 1.5s |
| 音效 | 打字机哒哒哒 + 句末低沉「咚」；环境音始终垫底 |

### 4.2 正片字幕

- 白字粗体 + 黑色 20% 不透明度描边（任何底色可读）
- 强调词单字/词组微高亮（保持克制，不花哨）
- **方言原话保留原文**，不替换成普通话——真实性资产，也是 AI 语料展示点

### 4.3 调色

- 不套商业滤镜；轻微降饱和 + 提阴影，保留环境「脏感」
- 人不做电子磨皮——粗粝即人设

### 4.4 封面/头像

- 封面三固定位：左上「田野日志 00X」/ 中央主体（暗化氛围图）/ 底部 Slogan
- 头像：黑底白字「曹亚仑」三字排布，与字卡视觉同源（可以先用文字版，后续再品牌化）
- B站头图右侧放栏目说明：「每周：田野日志 / 工作流」
- **静态资产由脚本可复现生成**（黑底白字代码渲染版，裁剪/调字重在剪映落地）：
  `python3 scripts/render-brand-cards.py`（`--list` 看清单，可只渲染单张）→ 输出至 `docs/资产/品牌/`

  - `ep000-cover-{horizontal,vertical}.png`／`ep000-opener.png`／`ep000-quote{,-vertical}.png`／

- **v2 改版记录（2026-09-12）**：v1 无版式约束，出三处缺陷——① hero 巨字与底部 slogan 共栏，

## 六、发布与迭代机制

### 6.1 发布日历（两周一轮）

## 七、合规与边界（不可省）

- **受访授权**：出镜前口头征得同意并留证；敏感话题受访者要求不播的内容一律剪掉
- **不消费苦难**：弱势群体素材只记录、不诱导卖惨；标题不做夸大
- **边界定位**：明确定位为「个人记录 / 内容创作」，不碰新闻采访资质敏感区
- **数据资产**：访谈原始录音/转写文本本地留存（.qoder 或本地存储），注明是否可商用（To B 语料售卖的授权前提）

## 八、FDE 工作流工具链 v1（采集 → 转写 → 提炼 → 核对/分发）

> 原则：能用免费/已有工具先跑通，不为工具提前消费；每步有人工核对点——AI 只做转写与提炼，选题与提问永远是人。

### 8.1 四步工作流

| 步骤 | 工具（v1 建议） | 产出 | 验收标准 |
|------|----------------|------|----------|
| ① 采集 | 手机主摄 + 领夹麦 + 手机自带录音双保险；横屏机位主录、竖屏构图保底 | 原始录音/视频 | 对话清晰、空场 30s 环境音已录 |
| ② 转写 | 剪映字幕识别（免费主力）/ 通义听悟（长语音、多说话人）/ Whisper 本地（隐私优先） | 带时间轴的转写稿 | 方言错误率可接受（翻车现场留作工作流栏目素材） |
| ③ 提炼 | LLM（Kimi / 豆包 / Claude）跑结构化 Prompt | 结构化卡片：时间线 / 情绪点 / 金句候选 / 主题标签 | 金句候选至少 5 条、可回溯到转写稿时间戳 |
| ④ 核对 + 分发 | 人工对照原声核对金句 → 剪映成片 → 无水印导出 | 成片 ×2（横屏完整版 / 竖屏精华版） | 金句与原声逐字一致（方言不替改） |

### 8.2 提炼 Prompt 模板（直接可贴）

```
以下是田野访谈转写稿（附时间戳）。请输出：
1. 时间线：受访者讲了哪几个阶段（按话题分段，各 1 行摘要）
2. 情绪点：语气、停顿、叹气等文本外信息无法体现的，标注需人工听原声确认的位置
3. 金句候选：5-8 句，逐字抄录（方言保留原文，不翻译），附时间戳
4. 主题标签：3-5 个，用于封面与标题
5. 可延伸问题：受访者话里露出的、值得下次追问的缝隙
```

### 8.3 素材归档（每期一目录）

```
dates/2026-09-XX-园丁/
├── 01-原声/     录音 + 视频素材（按「第X段」分段）
├── 02-转写/     转写稿（时间轴版）
├── 03-提炼/     结构化卡片 + 金句核对稿（标★为已确认可用）
├── 04-成片/     横屏完整版 + 竖屏精华版 + 封面
└── meta.md      受访者代号、授权记录、联系方式、可商用与否
```

### 8.4 工具链的 To B 铺垫

- 每期 `02-转写/` + `03-提炼/` 即结构化语料雏形：12 期后可汇总成「田野洞察报告」（M2 用）
- 语料可商用性在 `meta.md` 记录——这是未来卖给 AI 厂商/品牌方的授权前提
