## 2. 拍摄与成片规范

| 项 | 标准 |
|---|---|
| 画幅 | 横屏 16:9（B站/YouTube/长视频）；竖屏 9:16（抖音/视频号/小红书） |
| 分辨率 | 拍摄 4K 起步，输出 ≥1080p |
| 收音 | 外接麦克风优先；现场嘈杂就降噪，人声清晰优先于画质 |
| 响度 | 统一目标响度（流媒体常用 -14 LUFS），成片前后一致 |
| 字幕 | 所有内容必加字幕；白字黑边或平台默认样式；零错别字 |
| 封面 | 统一构图与字体系统，现场实拍优先 | DESIGN §5.6 |
| 时长 | 长视频 8–20 分钟；切片 30–90 秒 |
| 素材比重 | 「真实反馈素材」（原话/现场）不低于全片 50%——守住「有依据」 |
| 归档 | 命名 `2026-09-11_外卖骑手收入_剪V2.mp4` 式；素材 3-2-1 备份 |

## 3. 发布与运营 SOP

- **发布窗口参考**（先按此跑 30 天，再用自己的数据修正）：公众号/B站 晚 20–22 点；抖音 12–14 点与 18–20 点；小红书 12 点与 18–22 点。
- **标题测试**：发布 2–4 小时后 CTR 低于平台中位（参考 3%）→ 换备选标题重测。
- **互动**：发布后 1 小时内回复高价值评论；置顶一条提问式引导评论。
- **主页**：简介 = 一句话定位 + 更新承诺；置顶 = 代表作 + 方法论总览。
- **分发**：按 DESIGN §6.7 逐平台适配；同一素材的多形态分发由 Console 分发矩阵跟踪，状态即时更新。

## 4. 数据周报与月报

**周报**（每周一 30 分钟，数据来自 Console 快照）：

| 项 | 本周 |
|---|---|
| 发布数 / 播放 / 阅读 | |
| 完播率 / 互动（评·转·藏） | |
| 涨粉（净增） | |
| 高价值评论 3 条（原话） | |
| 下周唯一要做的一件事 | |

**月报**（围绕 DESIGN §9.2 六层 KPI，对照上月）：

- 影响力/参与/信任/质量/结构/商业，每层 2–3 个数字与上月对比；
- 田野场次与受访者库增量；
- 支柱覆盖统计：哪根支柱缺位（对应 Console 总览）；
- 下月选题漏斗结果（§6.6 四问跑完的选题列表）。

## 5. 单期复盘模板（reviewNote 展开）

1. 这期做得好的 3 点；
2. 没做到/翻车的 1–2 处（含公开更正记录，§8.3）；
3. 数据观察：播放/完播/互动与往期对比；
4. 观众反馈摘录 3 条（原话，经同意）；
5. 下次唯一要改的 1 件事；
6. 合规自查：同意清单（§8.5）与 AI 披露（§8.8）是否走完。

## 6. 冷启动与增长策略（0→1→10）

- **冷启动三原则**：单个主阵地打透再扩；真人出镜；前 5 条当标杆反复打磨。
- **增长杠杆**：爆款回归分析（什么选题/标题/时长带来量）；评论区与私信高频问题 → 下一期选题（反馈即田野）。
- **借势规范**：行业新闻可回应，但必须有第一性视角与真实证据；不蹭无关联热点。
- **联动**：受访者发布后联动转发（共赢）；同行互访做内容。
- **红线**：不买粉、不刷量、不进互夸群——违反平台规则，也违反品牌本质。

## 7. 平台合规红线清单

- **通用**：原创首发声明；一鱼多吃在各平台做「改编」而非原样搬运；违禁词自查。
- **商单报备**：按平台规则走报备（抖音星图 / 小红书蒲公英 / B站花火等）。
- **敏感领域**：医疗/金融/教育等内容不承诺疗效与收益（真实案例也克制用词）。
- **音乐版权**：优先平台曲库；外部音乐需商用授权并留凭据（§8.7）。
- **未成年人**：涉未成年人出镜需监护人书面同意。
- **立场**：以上是底线而非「规避技巧」；发现违规立即下架并公开更正（§8.3）。

## 8. 私域运营 SOP

- **引流**：主页简介/置顶评论放一处入口，克制不轰炸。
- **欢迎语模板**：「这里是「极致工程」的反馈角——不卖课轰炸，只说真实使用反馈；不想待随时退。」
- **节奏**：每周 1–2 条有效信息；反馈回收表沉淀进选题库（DESIGN §6.6/§6.10）。
- **禁**：私聊卖课轰炸、买水军、泄露成员信息。
