## 1. 品牌核心

### 1.1 黄金圈（Why / How / What）

- **Why（为什么存在）**：我相信卓越来自「系统调教 + 真实世界反馈」，而非天赋与包装。把身体、认知、AI Agent 调到极致，并把各行各业的真实反馈带到台前——这是任何领域都适用的底层操作系统。
- **How（怎么做）**：第一性原则；Maxing everything；田野调查；Build in public。
- **What（做什么）**：视频（主线）、文章、出版物、App/小程序/Web App。

### 1.2 品牌本质（Essence）

**极致的真实（Real to the Max）** —— 一头是「极致」（工程、方法、调教），一头是「真实」（反馈、现场、接地气）；两者互相约束：极致不能以失真为代价，真实不能以粗糙为借口。

### 1.3 使命与愿景

- **使命**：把各行各业真实的一手反馈做成内容，把身体/认知/AI Agent 的极致调教做成可照做的方法。
- **愿景**：成为「真实一手反馈 + 极致工程」被信任的代名词——想看点真实的东西时，想到我。

### 1.4 价值观（行为表现 / 反例）

| 价值观 | 意味着 | 反例（绝不） |
|---|---|---|
| 真实优先 | 素材用一手反馈；承认不知道；公开失败 | 二手观点充数、包装人设、事后美化 |
| 极致执行 | 身体/认知/AI Agent 持续调教；输出打磨到可回看 | 把半成品当坦诚的借口 |
| 第一性 | 从原理出发；质疑流行叙事 | 人云亦云、蹭热点话术 |
| 公开构建 | 过程、数据、复盘公开 | 只晒结果不晒过程 |
| 接地气 | 说人话；现场感；不端着 | 术语堆砌、居高临下 |

### 1.5 品牌叙事（结构已定，个人经历待补写）

叙事弧（行业标准：起源 → 触发 → 觉醒 → 践行 → 承诺），第一人称、平视、不卖惨不造神：

- **起源/触发**：〔待补：什么经历让你认定「系统大于天赋」〕
- **觉醒**：成长的瓶颈不是信息不够，是系统没调好——极致工程就是两句话：第一性原则，maxing everything。
- **践行**：把身体、认知、AI Agent 都保养和调教到极致；追求输出的影响力与质量。
- **承诺**：走进各行各业做田野调查，把最真实的反馈带进内容；所有输出都是我，build in public。

叙事草稿（【】处待填真实经历，禁止虚构）：

> 我一度以为成长的瓶颈是信息不够。后来发现不是——是我这台机器没调好。【待补：一次具体的转折/打脸经历】。
> 从那以后我只信两件事：第一性原则，和把事情调到极致——身体、认知、AI Agent，我都当成系统来保养调教。
> 再后来我意识到，光调自己不够：我要走进各行各业，把最真实的反馈带出来。我的所有输出都是我，我 build in public。

## 2. 品牌定位

### 2.1 定位陈述（标准格式）

> 对 **25–40 岁、追求真实成长与效率升级的知识工作者与创作者**，
> **曹亚仑的内容** 是 **一份基于极致工程的田野调查笔记**——
> 提供 **各行各业真实的一手反馈，以及身体/认知/AI Agent 可实操的调教方法**；
> 因为 **所有素材来自真实田野与亲身实践，所有过程公开可查，而非二手观点与人设包装**。

### 2.2 差异化对比

| 对标类型 | 它们普遍的形态 | 我的差异 |
|---|---|---|
| 鸡汤/成长博主 | 情绪共鸣、无证据口号 | 证据与真实反馈驱动 |
| 知识博主/课程 | 二手转述、系统化包装 | 一手田野 + 第一性拆解 |
| 测评/评测博主 | 产品视角、参数化速览 | 人与行业视角、真实使用反馈 |
| 纪录片/纪实栏目 | 旁观者叙事、精致制作、疏离感 | 参与者视角、本人下场、接地气 |
| 效率/AI 工具博主 | 工具清单、流量驱动 | 先把身体/认知/AI 调到极致，再谈工具 |

### 2.3 替代选择

观众不看我的内容时会看：书与课程、其他类博主、纪录片与新闻报道、身边朋友的经验。差异化的检验标准：以上替代物给不了的「一手反馈 + 可照做系统」，正是本品牌的核心供给。

### 2.4 对标与借鉴（方法源，非模仿对象）

| 对象 | 领域 | 借鉴点 | 不学什么 |
|---|---|---|---|
| 《十三邀》 | 深度访谈 | 对受访者的尊重、不设防的对话 | 精英叙事与疏离感 |
| 《人生一串》 | 纪实美食 | 烟火气、接地气的现场感 | 栏目化包装套路 |
| swyx（learning in public） | 创作者方法论 | 学习过程公开化 | 纯英文技术语境 |
| levelsio（build in public） | 独立开发 | 过程即产品、数据透明 | 争议性营销手法 |
| Bryan Johnson（Blueprint） | 身体系统化调教 | 身体数据化、可测量的调教 | 极端化生活方式 |

### 2.5 品牌架构（主品牌背书制，不立第二人设）

| 层级 | 名称 | 角色 |
|---|---|---|
| 主品牌 | 曹亚仑 | 我即品牌：所有输出统一背书 |
| 方法论子品牌 | 极致工程（Extreme Engineering） | 旗帜概念：书/课程/专栏的名称 |
| 产品子品牌 | MeOS | 个人操作系统（出版物/App/小程序/Web App） |
| 内容栏目 | 田野调查系列（栏目名待定，如「田野实录」） | 视频主线栏目 |

原则：子品牌只做「栏目包装与方法论命名」，不产生第二人格；一切子资产挂主品牌背书。

## 3. 受众

### 3.1 核心受众：「系统型成长者」

28–40 岁，工程师/知识工作者/独立创作者。
- **痛点**：信息噪音里分不清真假；工具买了一堆没效果；成长路径是碎片拼图。
- **想要的**：真实案例、可执行系统、第一手反馈、经得起验证的方法。

### 3.2 次级受众

- **田野受访行业从业者**：各行业一线人员，既是受访者也是观众。要求：被如实呈现、行业被尊重。
- **同行创作者 / build in public 关注者**：要过程、数据、失败，不是秀。

### 3.3 非目标受众（明确不服务谁）

要速成爽感的人；要人设表演的人；只要情绪价值不要证据的人。不追这类流量。

### 3.4 受众旅程（四阶段承诺）

| 阶段 | 观众状态 | 品牌承诺 | 主要触点 |
|---|---|---|---|
| 发现 | 刷到一条内容 | 入口真实具体，不标题党（§5.6） | 标题/封面/切片 |
| 关注 | 看完决定关注 | 每期都有可验证的真实反馈 | 长视频/主页 |
| 信任 | 持续追更与互动 | 过程数据透明，纠错会认（§8.3） | 评论/私域 |
| 行动 | 用方法、买作品 | 方法可照做，作品可回看（§9.1） | 出版物/App/社群 |

## 4. 品牌人格

### 4.1 原型（Archetype）

- **主原型：探索者（Explorer）** —— 走入各行各业，带回真相。
- **副原型：智者（Sage）** —— 第一性原则拆解，把真相变成方法交给观众。
- **叙事基调**：发现 → 带回 → 拆解 → 交付。

### 4.2 五维人格（Aaker，1–5 分）

| 维度 | 分值 | 表现 |
|---|---|---|
| 真诚 Sincerity | 5 | 接地气、诚实、务实 |
| 胜任 Competence | 5 | 严谨、方法化、可靠 |
| 刺激 Excitement | 3 | 现场感与发现的兴奋，但不用夸张话术取悦 |
| 精致 Sophistication | 2 | 不塑造精英距离感（刻意「冷静/高冷」已弃用） |
| 粗犷 Ruggedness | 3 | 敢下场、敢进现场、不怕脏活 |

### 4.3 我即品牌（身份一致性）

品牌 = 我本人，我的所有输出都是我，不立第二个人设。一致性检查：任何内容拿出来，署名换成别人就不成立。

## 5. 语调与表达规范（Tone of Voice）

### 5.1 调性三关键词

| 关键词 | 含义 | 示例句式 |
|---|---|---|
| 接近真实 | 现场、原话、过程，不表演 | 「这期我去了 X，跟 Y 聊了三个小时，先说结论——」 |
| 接地气 | 说人话，不端着 | 「这不是教程，是我调教过程的记录，你拿去能改就用。」 |
| 有依据 | 给证据、给出处、承认不知道 | 「我查到两份资料互相矛盾，把分歧摆出来……」 |

### 5.2 弃用关键词

纪录片调调 / 冷静 / 高高在上 / 自我标榜「纪录片级」——真实感靠扎进去，不靠疏离与摆姿势。

### 5.3 Do / Don't

**Do**：第一人称；给数据/原话/出处；先讲现场再讲道理；把「我不知道」说出口；回应纠错并更正。
**Don't**：播音腔与深沉旁白；过度剪辑炫技；贩卖焦虑；绝对化断言（最强/没有之一）；把受访者原话改写成自己的话。

### 5.4 词库

- **多说**：反馈、现场、数据、复盘、调教、第一性、过程、失败、验证、证据。
- **慎用/禁用**：家人们、干货满满、绝绝子、全网最强、逆袭、坚持就是胜利、马上私信我。

### 5.5 口吻样本

1. **视频开场**：「这期我不是去采访，是去干活。跟修了十八年车的老师傅待了三天——他跟我说的第一句话就推翻了我的假设。」
2. **方法论表述**：「第一性原则就是拆到底：为什么要这个结果？证据在哪？剩下的都是惯性。」
3. **回应质疑**：「评论区这位指出的问题我核实了，确实是我错了。更正如下，感谢纠错。」

### 5.6 标题与封面（视频主线的门口规范）

- **标题**：真实、具体、带现场，能勾起好奇但不标题党。句式偏好：「我去 X 干了 Y」「跟 Z 聊了 N 小时，发现……」「我把 X 调到极致之后……」
- **禁用标题**：「震惊」「全网第一」「必看」「三分钟学会」「最后一天」。
- **封面**：现场实拍 + 大字标题；不用夸张表情/红圈箭头；全套封面保持同一字体与构图系统（对应 visualNotes）。

## 6. 内容战略

### 6.1 内容支柱（BrandPillar）

| 支柱 | 一句话 | 代表形式 | 示例选题 |
|---|---|---|---|
| 极致工程方法论 | 第一性原则与 maxing everything 的框架和应用 | 长文/系统课/拆解视频 | 「如何给认知系统做性能测试」 |
| 田野调查实录（主线） | 各行各业真实反馈进视频 | 实地/访谈长视频 | 「外卖骑手的真实收入账本」 |
| 自我调教日志 | 身体/认知/AI Agent 的公开调教与数据 | 周期短片/图文 | 「30 天睡眠-训练-LLM 管线改造」 |
| 公开构建 | 出版物/App/小程序/Web App 的构建与发布 | 开发日志/演示 | 「build in public：我的个人操作系统 v0.3」 |

### 6.2 田野调查标准流程（内容标准）

1. **定题**：从真实痛点与好奇出发（第一性提问）。
2. **进入**：每行业至少 3 位受访者或连续现场观察。
3. **采集**：深度访谈/跟场；告知用途、征得同意（见 §8.2）。
4. **记录**：保留上下文，引用原话，不剪辑歪曲。
5. **呈现**：反馈 → 拆解 → 落地方法。
6. **回访**：关键引用发布前请受访者确认。
7. **复盘**：写 reviewNote（什么有效/下次改进）。

### 6.3 视频内容公式

钩子（真实问题/反直觉发现，不用夸张手法）→ 现场（实拍+原声）→ 真实反馈（原话上屏）→ 第一性拆解（为什么会这样）→ 落地（能怎么用）→ 互动（请观众提供反馈——反馈本身也是田野）。

### 6.4 一鱼多吃转化链

长视频 → 切片/口播短片 → 图文长文 → 观点短帖（金句+原话）→ newsletter 摘要 → 出版物素材库。

### 6.5 节奏建议（可调）

| 周期 | 内容 |
|---|---|
| 每周 | 自我调教日志 / 短文 |
| 每月 | 田野调查长视频 1–2 条；深度图文 2–4 篇；月度复盘 |
| 每季度 | 定位与支柱校准（回看本文件） |

### 6.6 选题漏斗与筛选标准

- **选题来源**：田野见闻、观众反馈（评论/私信，反馈本身即田野）、极致工程里的矛盾点（身体/认知/AI 某处被打脸）、支柱覆盖补位。
- **筛选四问**（全部通过才立项）：
  1. 有没有真实反馈可验证？（不是二手观点）
  2. 能不能拆到第一性？（故事之外有理）
  3. 观众能不能照做？（有落地动作）
  4. 符不符合调性三关键词？（接近真实/接地气/有依据）
- **优先级**（对应 ContentItem.priority）：高 = 真实反馈 × 高普适；中 = 单点深入；低 = 过程记录。

### 6.7 平台适配（一鱼多吃的形态细则）

原则：**内容不变，形态变；不为一平台改立场。**

| 平台 | 形态 | 语气微调 |
|---|---|---|
| 公众号 | 完整方法论长文 | 结构完整、可收藏 |
| 小红书 | 原话金句 + 图文 | 少术语、视觉第一 |
| 抖音 | 切片 + 强钩子 | 最口语、前 3 秒给结论 |
| 视频号 | 长视频 + 转发语 | 场景化开头 |
| B站 | 深度长视频 | 保留完整过程与弹幕互动点 |
| X | 过程帖/摘要（英文可） | 数据、进度、复盘片段 |

各平台的差异化定位写入 PlatformChannel.positioning 字段。

| 高频触达 | 抖音（切片）/ 小红书（金句图文） | 导流回主阵地 |

### 6.10 私域与反馈回路

- 私域（微信/社群）定位：田野的自然延伸——收集真实反馈，不是割韭菜通道。
- 原则：反馈进选题库（§6.6 来源 2）；高价值回复经同意后公开化；不私聊轰炸。
- 回路：发布 → 评论区/私域回收 → 下一期田野或复盘里回应。

### 7.2 视觉方向（草案）

- **原则**：实录优先、低修饰、稳定一致。
- **方向**：真实生活照头像（非棚拍精修）；封面用现场实拍 + 大字标题；低饱和自然色系。
- **不做**：磨皮滤镜、过度调色、摆拍感、统一网红模板。
- **品牌资产包（待落地）**：头像、主视觉/封面模板、标题字体、字幕样式、水印、栏目片头（如有）——每项产出后归档于品牌资产页。

## 8. 规范与边界（伦理）

### 8.1 Build in public 边界

- **公开**：方法论、过程、数据、失败与复盘、创作思考。
- **不公开**：受访者未经同意的内容、他人隐私、未发布作品的敏感细节、财务敏感信息。

### 8.2 田野调查伦理（内容红线）

- 每次访谈：告知用途、征得同意（出镜/引用）。
- 受访者可选署名或匿名；关键引用发布前请其确认。
- 保留语境，不歪曲原意；受访者有权撤回。
- 对占用时间的受访者保持感谢与回馈惯例。

### 8.3 更正与反馈机制

- 错误公开更正（正文修正 + 评论区置顶说明）。
- 观众纠错优先处理，并把纠错案例做成内容素材。
- 定期审计田野样本代表性（是否偏斜单一群体）。

### 8.4 商业合作红线

- 只合作**真实使用过、与极致工程调性一致**的产品/服务；结论不因商单改变（好就是好，不好就明说）。
- 合作内容**明确标注**；优先推荐对观众真实有用的方案，哪怕免费。
- 拒绝：夸大宣传、割韭菜模式、要求数据造假、与调性冲突的品类。

### 8.5 受访者同意清单（田野合规底线）

发布前逐项确认（被打磨成可复用的同意模板，放入 Console 分发区附件）：

- [ ] 已告知内容用途与发布平台
- [ ] 已确认出镜/引用范围（可只语音、只文字）
- [ ] 已选择署名或匿名
- [ ] 关键引用已由受访者过目确认
- [ ] 已告知撤回权与联系方式
- [ ] 已完成感谢/回馈惯例

### 8.6 风险与争议处理

- **行业争议题材**：呈现多方反馈与完整上下文，不预设立场；给相关方回应机会。
- **被断章取义**：公开完整素材与上下文，不删帖回避。
- **数据质疑**：数据可复核，来源公开；无法复核的明确标注为「估计值」。

### 8.7 内容权利与合规

- 素材版权：音乐/字体/图片/视频只用已授权来源（含 CC/商用授权），留存授权凭据。
- 肖像与场所：受访者同意（§8.5）；非公开场所拍摄先取得许可。
- 广告合规：合作内容明确标注（§8.4），遵守各平台广告标注规则。

### 8.8 AI 使用与披露原则

- AI 是调教对象与工具，不是枪手：田野核心素材（受访者言论、现场）必须真人真事。
- AI 辅助（脚本草稿/剪辑/配图/翻译）按平台惯例在成品中标注。
- 禁止用 AI 虚构「真实反馈」；任何 AI 模拟案例必须明确标注为模拟。
- 出版物/教学中 AI 生成内容披露比例与边界。

## 9. 衡量与复盘

### 9.1 北极星

- **影响力**：真实反馈被看见且被记起的次数（田野内容月完播人次 × 高价值互动）。
- **质量**：90 天回看率（发布 90 天后仍被访问/引用的内容占比）。

### 9.2 KPI 体系

| 层级 | 指标 |
|---|---|
| 影响力 | 总播放/阅读、月新增粉丝、单条峰值 |
| 参与 | 完播率、评论率、转发收藏 |
| 信任 | 高价值评论占比、被转载/引用次数、纠错致谢率 |
| 质量 | 90 天回看率、复盘完成率、田野场次/月 |
| 结构 | 支柱覆盖均衡度、渠道健康度（对应 Console 总览） |
| 商业 | 出版物/作品使用与销量、合作邀约 |

### 9.3 复盘节奏

每期 reviewNote（Console 内置）→ 月度渠道与数据复盘 → 季度定位与调性校准。

### 9.4 品牌预发布检查清单（Editorial Checklist）

发布前逐项过一遍（建议固化为 Console 分发前的强检查）：

- [ ] 调性三关键词全会过？（接近真实 / 接地气 / 有依据）
- [ ] 证据、数据、出处齐备，绝对化断言已清除（§5.4 禁用词扫描）
- [ ] 受访者同意清单已走完（如适用，§8.5）
- [ ] 标题与封面符合 §5.6（不标题党、现场感）
- [ ] 一鱼多吃与平台适配已规划（§6.7）
- [ ] 一致性检查：署名换成别人是否成立？（§4.3）

### 9.5 发展阶段与里程碑

| 阶段 | 目标 | 验收 |
|---|---|---|
| 0→1 启动（3 个月） | 品牌资产落地（slogan/视觉/档案）；首批内容覆盖 3 个支柱；跑通一次完整田野流程 | 6 条内容、首个田野长视频、同意模板就绪、受访者库 ≥5 |
| 1→10 验证（6 个月） | 单一主阵地跑通；北极星指标有基线；复盘机制运转 | 月更稳定、90 天回看率可读、KPI 看板可用 |
| 10→100 扩张 | 多平台矩阵；出版物/App 发布；商业合作开场 | 双主阵地、作品库 ≥2、商单符合 §8.4 |
