## 0. 执行摘要（TL;DR）

1. **五个品类的证据覆盖高度不均**：测评/极致制作类、纪录片/纪实类证据最充分；知识付费类有量级数据但多为卖课者自报口径；**鸡汤/成长与效率/AI 工具两类没有任何存活验证数据**，结论外推需谨慎。
2. **现有头部账号分别验证了四个组分能力，但无人把它们组合成固定栏目**：
   - 探访形态（于谦《多新鲜呐》：14 支视频 3200 万+ 播放）
   - 访谈形态（罗永浩《罗永浩的十字路口》：B站 2025 百大「年度最佳新人」）
   - 极致考据（星球研究所：选题→查证→内审→外审；卢格杜努姆的奥古斯丁：25 分钟均长考据视频，2026.09 实测 125.3 万粉）
   - 极致制作 + 电商变现（影视飓风：2024 营收破亿、电商占比超 50%）
   - **「+ build in public 方法论公开」——没有任何一家做到**
3. **空白生态位结论**：「田野调查 × 极致工程」定位正落在此空白处：中文市场尚未出现把「平民/小众圈层探访 + 极致考据工程流程 + 方法论公开（build in public）」组合成可复制固定栏目的账号。各组分能力均有已验证的对标样本可借鉴。
4. **变现路线图**：电商/IP 周边（影视飓风式）与图书出版（星球研究所式，码洋超 2 亿）是已验证出口；**知识付费短期效率最高（单课千万级）但透支口碑风险已被影视飓风 49 元 AI 课风波实证**——须慎重。

## 1. 五类竞品深挖

### 1.1 测评/评测博主（③）

#### 影视飓风 —— 极致制作的商业天花板样本

- **定位与差异化**：专业影视自媒体，核心口号「无限进步」。人设 = 硬核技术 + 纪录片级制作，连续 7 年（2019–2025）B站百大 UP 主。护城河是**重投入的工程化生产体系**（约 150 人团队、不融资、现金流为正），不是个人魅力。
- **内容与形式**：测评 + 行业深度内容 + 自制栏目；2025 年获 B站最多弹幕 237 万条（另有投币 905 万佐证），互动密度为全站顶级。
- **数据与增长**：全网粉丝 2800 万+（2026.01 媒体口径）；B站 1346.6 万（2025.09）→ 1482 万（2026.01）→ **1741 万（2026.09 B站官方 API 实测）**。
- **变现模式**：2024 年营收破亿但利润仅千万级（重成本结构）；收入结构 = 商单 + TVC 广告 + 电商，**电商已超 50% 成为最大来源、广告仅约 10%**，2025 年单件 T 恤售出 20 万件。知识付费尝试存在但口碑受损（见 §1.3 反面案例）。⚠️ 营收/销量为创始人自报口径，非审计数据（n=1 案例，一般化需谨慎）。

#### 何同学 —— 讲故事护城河 + 单点爆款冷启动

- **定位与差异化**：科技测评，但**护城河是「讲故事」而非技术展示**——「站在 2013 年看当下的 4G」式类比，把复杂技术讲给普通人。
- **内容与形式**：单点深度长视频、高制作、强叙事钩子；少而精（数月一更级别）。
- **数据与增长**：冷启动 = 单点爆款破圈 + 平台红利——2019-06-06《有多快？5G 在日常使用中的真实体验》发布次日 B站同时观看 2 万+，两年内粉丝 29 万 → 880 万（2021.12）。「智能桌子」视频（2021-10-17，7 分 48 秒）发布次日**直接拉动赞助商乐歌股价单日 +13.51%（市值 +约 5.5 亿，经东方财富行情数据核验）**——硬核制造内容的商单带货效应可产生直接市场影响。
- **变现模式**：品牌商单/赞助（乐歌、OPPO 等）+ 平台激励；主打大牌合作而非自有产品。

### 1.2 纪录片/纪实栏目（④，含访谈/探访/考据新形态）

#### 星球研究所 —— 极致考据流程 + 图书变现样板

- **定位与差异化**：「一群国家地理控，专注于探索极致世界」，**用地理做科普**；人设 = 基于极致考据的科普团队。护城河是**生产线级内容流程：选题 → 查资料 → 文案 → 内部审核 → 外部专家第二次审核 → 反复确认（双轮审核）**。
- **内容与形式**：10 分钟级图文/视频长篇科普；周期长、密度低、考据重。
- **数据与增长**：《100 年重塑山河》视频号单条播放 1 亿、涨粉 30 万+（截至 2021.07 账号粉丝近 70 万）——纪实/科普类在视频号具备单条亿级爆款潜力。
- **变现模式**：**内容产品 + 广告**，核心为《这里是中国》系列图书（《这里是中国 1》码洋超 2 亿；《这里是中国 3》2024.09 出版）——走「内容口碑 → 图书/品牌」路径，无付费课程。

#### 竹内亮 —— 「真实」人设与好奇心选题

- **定位与差异化**：旅华日本纪录片导演；选题标准 = **「个人的好奇心」而非中外观众偏好**（原话：「这个题材是外国人感兴趣的，这个是中国人感兴趣的，我不是这样选择」）；人设护城河 = 真实（「我是纪录片导演，我装不了自己」）。被央视网/人民画报/中纪委网站等跨平台多年采访反复印证——**「真实 + 个人视角」在纪实赛道具备持续差异化能力**。
- **内容与形式**：《我住在这里的理由》等系列，长线跟拍 + 人物访谈；保持个人 IP 化、系列栏目化。
- **数据与增长**：B站/微博头部纪实 IP（2021 年前已积累）；长线栏目沉淀，未依赖单点爆款。
- **变现模式**：**量化数据缺失**（2021 年后的商单/出版路径无验证数据；「纪录片赚钱难/能吃饱就行」的说法已被核验团队 0-3 票证伪，不能引用）——纪实类变现上限仍悬空，需一手调研。

#### 于谦《多新鲜呐》 —— 探访形态的平台级认证（离田野调查最近的形态）

- **定位与差异化**：相声演员于谦的视频播客，**探访各个小众文化圈层**——最接近「田野调查」外壳的已验证形态。
- **内容与形式**：小圈子实地探访 + 轻访谈，名人 + 素人场景混搭。
- **数据与增长**：仅 14 支视频取得 **3200 万+ 播放**；与罗永浩《罗永浩的十字路口》同获 B站 2025 百大「**年度最佳新人**」（2026-01-19 颁奖，多家媒体当日独立报道）——**B站平台级认证：小圈子/平民探访有千万级播放的流量天花板**。
- **变现模式**：未公开细项（名人 IP 背景，非核心参照）。

#### 罗永浩《罗永浩的十字路口》 —— 高势能访谈破圈

- **定位与差异化**：深度访谈李想、何小鹏、影视飓风等嘉宾（B站视频 + Apple Podcasts 跨平台分发），借**高势能嘉宾放大流量杠杆**。
- **内容与形式**：长访谈栏目形态，（截至调研时）未方法论化/未成固定栏目。
- **数据与增长**：现象级栏目（「现象级」为媒体定性用语），2025 百大「年度最佳新人」；罗永浩微博被禁言后的公开亮相自带事件流量。
- **变现模式**：未公开细项；对个人品牌的参照是**破圈杠杆**而非变现模板。

#### 卢格杜努姆的奥古斯丁 —— 极致考据长视频（垂直深耕样本）

- **定位与差异化**：中世纪史考据 UP 主；**25 分钟均长的深度考据长视频**。
- **内容与形式**：垂直领域极致考据，单集超长、全程引证。
- **数据与增长**：106 万粉（2026.01）→ **125.3 万粉（2026.09 B站 API 实测）**；中国经营网（2026-01）评论：「流量不再是唯一标准，**硬核内容和垂直深耕开始成为新门槛**」（评论文章观点，非实证）。
- **变现模式**：未公开细项；参照价值在**内容方法论**（极致考据 × 垂直深耕 × 平台趋势背书），不在变现。

### 1.3 知识博主/课程（②）

#### 李一舟 / 张琦 / 粥左罗 —— 变现效率最高，但口径需打折

- **定位与差异化**：流量型知识付费 IP；「清华博士」「商业导师」人设（李一舟头衔存争议，公司已因虚假宣传被处罚）。
- **内容与形式**：短视频引流 + 直播/信息流卖课；内容硬核度低，依赖流量势能与强转化话术。
- **数据与增长**：李一舟 199 元《每个人的人工智能课》一年约售 25 万套、约 5000 万销售额（销量集中于 2024-02 病毒式爆红期；飞瓜数据/每经等交叉印证）；张琦「AI+生意新增长」定价 520 元；粥左罗《ChatGPT AI 变现圈》17 天 279 万。**⚠️ 多为卖课者自报口径、毛收入、退费未知**。
- **变现模式**：知识付费是五类中变现效率最高（单课千万级）且与 AI 题材强绑定，但**口碑透支风险高**——反面案例即影视飓风：49 元 AI 实战课直播间单日售出 10 万+ 份（约 490 万），差评密集（「模板化操作无自由度、生成效果与教程不符」），官方随后承认锁定 prompt。**教训：头部制作型团队卖课同样翻车，说明课程口碑风险是品类性的，不是执行问题。**

## 3. 空白生态位结论：「田野调查 × 极致工程」

> 综合判断证据等级：medium（基于 21 条已验证声明 + 检索范围内未发现既有竞品；「不存在」属调研语料内的结论，需定向复核）。

**中文内容市场尚未出现**把以下四者组合成可复制固定栏目的账号：

1. **田野探访/平民访谈形态**（于谦《多新鲜呐》式外壳 —— 已验证千万播放）
2. **极致考据工程流程**（星球研究所双轮审核式 / 卢格杜努姆式长考据 —— 已验证平台趋势背书）
3. **build in public 方法论公开**（无人把「怎么做田野」本身做成内容资产）
4. **高势能破圈杠杆**（罗永浩式嘉宾访谈、何同学式单点爆款）

每个组分都有已验证对标，但**没有一家把它们串成一个栏目并公开方法论**——这正是本品牌定位的落点：别人证了形态可行，我们证「形态 + 工程化流程 + 公开构建」的组合。
