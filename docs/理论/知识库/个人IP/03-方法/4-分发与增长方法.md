# 03-4 分发与增长方法：被看见与被记住

> 一句话：**内容是资产，分发是管线，增长是复利的结果。
> 本节给出一套「平台适配 + 渠道健康 + 北极星引导」的分发增长系统。**

---

## 1. 分发的基本盘：一鱼多吃矩阵（已定稿）

| 平台 | 形态 | 语气微调 | 平台角色 |
|---|---|---|---|
| 公众号 | 完整方法论长文 | 结构完整、可收藏 | 沉淀与搜索 |
| 小红书 | 原话金句 + 图文 | 少术语、视觉第一 | 获客与标签 |
| 抖音 | 切片 + 强钩子 | 最口语、前 3 秒给结论 | 破圈流量 |
| 视频号 | 长视频 + 转发语 | 场景化开头 | 私域联动 |
| B站 | 深度长视频 | 保留完整过程与弹幕互动点 | 主资产阵地 |
| X | 过程帖/摘要（可英文） | 数据、进度、复盘片段 | 同行与全球 |

**纪律**：
- 主资产（长视频/长文）只在 1-2 个「主阵地」首发（B站/视频号 + 公众号），
  其余走切片与摘要——不首发所有平台 = 保留编辑主导权；
- 各平台的差异化定位写入 PlatformChannel.positioning（Console 渠道字段）。

---

## 2. 渠道健康度模型

每个渠道用四个维度打分（月更）：**触达（曝光）· 转化（关注率）· 互动（评论/收藏率）· 沉淀（转入私域率）**

```
渠道健康评分 = 触达 × 0.3 + 转化 × 0.3 + 互动 × 0.25 + 沉淀 × 0.15
```

| 分数 | 处理 |
|---|---|
| ≥80 | 加注：提高供给（多给切片/更适合该平台的形态） |
| 60-79 | 维持：保持节奏，等待算法正反馈 |
| 40-59 | 诊断：是内容问题还是平台问题（对照同类账号） |
| <40 | 止损或重试：暂停 1 个月换形态重试；两次重试无效则降权 |

**结构性结论先行**：平台千差万别，但「主阵地深挖 + 一鱼多吃」的结构不变。

## 3. 增长模型：漏斗 + 北极星

### 3.1 漏斗（内容 → 关系）

```
曝光 → 观看 → 关注 → 互动 → 沉淀（私域/订阅）→ 复访（回看）
 │       │       │       │         │            └─ 90 天回看率（质量北极星）
 │       │       │       │         └─ 订阅/私域增量（资产北极星）
 │       │       │       └─ 高价值评论占比（信任北极星）
 │       │       └─ 关注转化率（内容对定位的吸引力检验）
 │       └─ 完播率（内容结构与节奏检验）
 └─ 曝光量（选题与标题检验）
```

### 3.2 北极星与 KPI 分层（品牌蓝本 §9 展开）

| 层级 | 指标 | 看什么 |
|---|---|---|
| 北极星 | 影响力：田野内容月完播人次 × 高价值互动；质量：90 天回看率 | 只盯这两个，其余为过程量 |
| 参与 | 完播率、评论率、转发收藏 | 内容质量过程量 |
| 信任 | 高价值评论占比、被转载/引用次数、纠错致谢率 | 信任资产过程量 |
| 质量 | 90 天回看率、复盘完成率、田野场次/月 | 系统健康过程量 |
| 结构 | 支柱覆盖均衡度、渠道健康度 | 定位不漂移 |
| 商业 | 出版物/作品使用与销量、合作邀约 | 变现阶梯进度 |

**纪律**：数据看趋势不看单日；单条爆或扑都是噪声，季度趋势才是信号。

## 4. 增长的操作面（不做不可控的事）

| 增长动作 | 是否做 | 说明 |
|---|---|---|
| 按算法调标题/封面 | ✅ | 属「可被验证的优化」，前提是不越质量门 |
| 蹭热点 | ⚠️ 限量 | 只蹭与本定位真实相关的热点，且必须能沉淀进作品库 |
| 投流 | ⚠️ 后期 | 前 1-2 年不投流：先验证内容本身成立 |
| 互推/群推 | ⚠️ 谨慎 | 只与调性一致的创作者互推，量少质高 |
| 刷量/买粉/苗 | ❌ 绝对不做 | 与信任资产直接冲突，一票否决 |
| 追评论吵架 | ❌ 不做 | 争议内容用「完整上下文」回应，不参战 |

**「被记住」的刻意设计**：每期内容留一个「记忆点」（一个反直觉数字、
一句原话、一个画面），比均匀地好内容更容易被转发与回想。

---

## 5. 增长节奏（周/月/季）

| 周期 | 动作 |
|---|---|
| 每周 | 发布主资产（按节奏表）→ 汇总各渠道数据到驾驶舱 → 处理高价值评论与纠错 |
| 每月 | 月度复盘（见 [5-复盘与迭代方法](./5-复盘与迭代方法.md)）→ 调整下周选题 |
| 每季度 | 重描渠道健康表 → 定位校准 → 样本审计 → 出口袋策略（停/增/改渠道） |

## 5.1 试点条款 B2：田野通讯订阅（迁移自 06 全球思维库）

> 机制来源：专家通讯（Gergely Orosz）+ 平台租地/私域买地（Li Jin）。
> 目标：跑通「私域 × 订阅」的最小闭环，把平台关注沉淀为可触达资产。

| 项 | 内容 |
|---|---|
| 目标 | 每月 1 期田野通讯（发布会前一手田野数据 + 复盘摘要） |
| 验证指标 | 订阅量、打开率、私域净增、零退订率中的「高价值互动」 |
| 时间窗 | 3 个月（发布 3 期后验收） |
| 步骤 | ① 低频邮件/微信通讯起始（月更，不追求日更）→ ② 每期 3 个板块：本期田野一手数据 / 一个失败复盘 / 下期预告 → ③ 渠道固定埋入口（视频简介、评论置顶、主页链接）→ ④ 数据进驾驶舱「沉淀环」 |
| 退出条件 | 3 期后打开率 < 15%，则暂停并复盘选题与预告口径 |

## 5.2 试点条款 B4：英文切片出海（迁移自 06 全球思维库）

> 机制来源：文化 IP 跨文化（李子柒）+ 过程帖（swyx/levelsio 的 X 实践）。
> 目标：验证「精选田野内容英文化」能否打开海外同行与创作者的反馈回路。

| 项 | 内容 |
|---|---|
| 目标 | 每月 1-2 条英文切片/过程帖（X + YouTube 短视频） |
| 验证指标 | 海外互动、被转载/引用、英文区高价值评论 |
| 时间窗 | 3 个月（每月 1 条起步） |
| 步骤 | ① 选「跨文化成立」的选题（行业真相、极致方法，弱依赖中文语境）→ ② 英文 AI 辅助翻译 + 人工校对（原话直译，不润色观点）→ ③ X 发过程帖（数据/失败/复盘片段）→ ④ 同步 YouTube 短视频做长尾 |
| 退出条件 | 3 个月后零高价值互动，暂停出海，转为「订阅者内部分享」 |

## 6. 分发增长自检

- [ ] 本期内容在多少个渠道有对应形态？（目标 ≥4）
- [ ] 各渠道本周数据是否已录入（Console 快照）？
- [ ] 北极星没有恶化？（影响力与 90 天回看率）
- [ ] 有没有任何增长动作违背了「不做不可控的事」？
- [ ] 私域/订阅本周有没有净增？（资产沉淀）
