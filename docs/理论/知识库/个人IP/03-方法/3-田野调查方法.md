# 03-3 田野调查方法：一手反馈的稳定供给系统

> 一句话：**田野调查是本 IP 的「调研部 + 选题银行 + 信任矿区」——
> 它有标准流程、有伦理底线、有可复制的质量门槛，不能让每一期都靠运气。**

---

## 1. 标准流程（七步，源自品牌蓝本 §6.2）

```
① 定题 → ② 进入 → ③ 采集 → ④ 记录 → ⑤ 呈现 → ⑥ 回访 → ⑦ 复盘
```

| 步 | 内容 | 质量门槛 |
|---|---|---|
| ① 定题 | 从真实痛点与好奇出发（第一性提问） | 能答「为什么是这个行业、这个问题」 |
| ② 进入 | 每行业至少 3 位受访者 / 连续现场观察 | 样本数 ≥3，场景真实可查 |
| ③ 采集 | 深度访谈/跟场；告知用途、征得同意 | 同意前置，越界即停 |
| ④ 记录 | 保留上下文，引用原话，不剪辑歪曲 | 原话可回放、可核对 |
| ⑤ 呈现 | 反馈 → 拆解 → 落地方法 | 反馈与观点分离标注 |
| ⑥ 回访 | 关键引用发布前请受访者确认 | 确认记录留档 |
| ⑦ 复盘 | 写 reviewNote（什么有效/下次改进） | 每期必写，回流选题库 |

---

## 2. 定题：第一性提问模板

从「现象」出发，连续向下问（每问三遍）：

```
现象：外卖骑手月入过万？
Q1 事实是什么？→ 收入构成（单量×单价−成本），哪些是平台规则，哪些是个人行为
Q2 约束是什么？→ 时间上限、算法规则、平台政策、行业周期
Q3 大家默认什么？→ 大众叙事里哪些未经证实（「跑得久就赚得多」？）
Q4 谁的真实反馈缺失？→ 一线骑手 / 站长 / 平台规则的执行者
```

**好选题的三个特征**：大众有直觉但缺证据；行业内部有分歧；拆开能让观众「照做或看清」。

## 3. 受访者获取（进入）

| 渠道 | 打法 | 注意 |
|---|---|---|
| 熟人网络 | 朋友介绍身边行业从业者 | 第一批 3-5 人最可靠 |
| 现场蹲点 | 从业者聚集地（门店、市场、站点） | 先建立信任再谈拍摄；不打扰生意 |
| 行业社群 | 微信群/论坛/B 站的从业者版面 | 说明用途，尊重匿名诉求 |
| 观众资源 | 评论区/私信自荐（互动即田野） | 这是漏斗闭环的天然通道 |
| 职业机构 | 行业协会、培训学校、招聘中介 | 素材更全，但注意「官方视角」偏差 |

**邀约话术模板**（见 [05-practice/3-田野调查实战](../05-实战/3-田野调查实战.md) 完整版）：
> 「我在做一个行业真实反馈的记录，不是采访也非背书。想跟你聊聊你工作的真实情况，
> 出镜方式你选，稿子你过目。占用你 60 分钟，会有小谢意。」

---

## 4. 采集与记录（质量的关键）

### 4.1 访谈结构（60-90 分钟）

```
0-5 分钟    寒暄 + 说明用途与边界（同意前置）
5-25 分钟   事实层：工作流程、收入、时间账本（数字问到底）
25-45 分钟  感受层：真实遭遇、后悔与骄傲（追问细节）
45-60 分钟  反直觉层：外界误解你什么？（打脸点常在这里）
60-75 分钟  方法层：如果重来你会怎么入行？（可照做点）
最后        回访约定：关键引用需要你过目；联系方式给到
```

**末尾的标准化尾节**：在上述情境化结构的最后，挂一段**每期完全相同的四个问题**（现状缺口 → 期待 → 入行故事 → 给当年自己的一句话）。它把两件本来互斥的事缝在一起——访谈的价值来自情境化（每期问的不该一样），语料的价值来自可比性（每期问的必须一样）。正因如此它只能是尾节，不能是主轴：拿标准化的四问当主结构，做出来的就是街头问卷，不是田野。

顺序、逐字问法、借词规则与红线在实践层单一维护：[`通用尾节四问.md`](../../../../实践/访谈IP/通用尾节四问.md)。本节只记它为什么成立，不复制问法。

### 4.2 追问纪律
- 数字问到底：「月入多少」→「哪个月？单量多少？单价多少？成本怎么算？」
- 拒绝概括：「大家都这样」→「你最近一次是几号？具体什么情况？」
- 允许沉默：沉默里常有真话，不抢话、不诱导（诱导 = 失真）。

### 4.3 记录规范
- 全程录音（已同意）双备份；现场照片含时间地点水印；
- 原话逐字记录，**不替换、不改写、不润色**；标注语气（笑/沉默/停顿）；
- 上下文保留：片段必须能指回完整对话（防止断章取义——也是自保）。

## 5. 呈现与回访（发布质量门）

### 5.1 反馈与观点分离
画面/文稿中明确区分：
```
【受访者原话】「……」（可直接核对）
【我的观察】……（标为个人判断）
【数据】……（标来源；无法核实的标「估计值」）
```
这是「有依据」调性的执行层，也是争议发生时的护身符。

### 5.2 回访确认（发布前 48 小时）
- 把涉及该受访者的片段逐条发给本人确认；
- 确认「出镜/语音/文字」范围、署名或匿名、有无撤回意愿；
- 确认记录留档（截图/邮件），作为同意流程的证据。

## 6. 常见偏差与修正（自检表）

| 偏差 | 表现 | 修正 |
|---|---|---|
| 样本偏差 | 只访到同一立场/同一人群 | 每行业 ≥3 人，且刻意找反方 |
| 幸存者偏差 | 只呈现成功样本 | 加访「没做成的人」 |
| 诱导失真 | 问题带倾向性 | 回放录音，删改诱导性提问片段 |
| 断章取义 | 只取爆点 | 以「上下文完整」为剪辑底线 |
| 礼貌性失真 | 受访者说场面话 | 交叉验证（同一事实问 3 人） |

**审计节奏**：季度末审计田野样本分布（行业/立场/性别/地域），
偏斜就把它做成补位选题——样本盲区本身是选题。

## 7. 产出标准（每期田野的固定产物）

| 产物 | 去向 |
|---|---|
| 原稿与素材包（录音/照片/笔记） | 存档（可复核，防断章取义） |
| 主视频 + 切片 + 图文 | 分发矩阵（一鱼多吃） |
| 新选题与新线索 | 选题库（反馈即田野的闭环） |
| reviewNote | 复盘系统（方法持续进化） |
| 受访者反馈与后续关系 | 受访者库（复访、回访、长期关系=信任资产） |

## 8. 自检清单（每期发布前）

- [ ] 行业样本 ≥3 人或连续现场观察成立？
- [ ] 同意清单逐项完成且有记录？
- [ ] 原话逐字准确、上下文完整、可回放核对？
- [ ] 关键引用已由受访者确认？
- [ ] 反馈与观点在内容中明确分离？
- [ ] reviewNote 已写？
