# 03-1 定位方法：把定位从直觉变成工程

> 一句话：**定位是工程不是灵感——有可复用的作业步骤、有明确的输出物、
> 有季度的校准节奏。本节给出全套作业方法。**

---

## 1. 定位五步作业法

```
① 黄金圈（Why/How/What 三问）
② 定位陈述（Geoffrey Moore 句式）
③ 原型与人格（Mark & Pearson / Aaker）
④ 差异化地图（对标分析 + 替代选择）
⑤ 验收与校准（四问 + 季度回看）
```

---

## 2. 步骤 ① 黄金圈作业（Simon Sinek）

写不出 Why 的定位是摆设。作业格式：

| 层 | 问题 | 本 IP 的答案（已定稿） |
|---|---|---|
| Why | 我为什么存在这个品牌？ | 卓越来自「系统调教 + 真实世界反馈」，而非天赋与包装 |
| How | 我怎么做？ | 第一性原则；Maxing everything；田野调查；Build in public |
| What | 我做什么？ | 视频（主线）、文章、出版物、App/小程序/Web App |

**检查**：Why 必须能回答「一个 25 岁的陌生人为什么要在 60 个博主的列表里选我」——
答案指向「信念 + 经历 + 方法」三者之一，而不是「内容品类」。

---

## 3. 步骤 ② 定位陈述（Moore 句式填空）

```
对 [目标受众]，
[我的名字] 的内容是 [品类]——
提供 [核心价值]；
因为 [差异化证据]。
```

本 IP 已定稿（DESIGN.md §2.1）：
> 对 **25–40 岁、追求真实成长与效率升级的知识工作者与创作者**，
> **曹亚仑的内容** 是 **一份基于极致工程的田野调查笔记**——
> 提供 **各行各业真实的一手反馈，以及身体/认知/AI Agent 可实操的调教方法**；
> 因为 **所有素材来自真实田野与亲身实践，所有过程公开可查，而非二手观点与人设包装**。

**验收三问**：
1. 受众是否足够具体（能说出他们约摸多少人、在哪出没）？
2. 品类词是否让听众立刻知道「这是什么」？（「田野调查笔记」✓ vs「内容生态」✗）
3. 差异化证据是否可被验证？（公开可查 ✓ vs 自我评价 ✗）

---

## 4. 步骤 ③ 原型与人格

### 4.1 原型（Mark & Pearson 12 原型）
- 主原型：**探索者 Explorer**——走入各行各业，带回真相。
- 副原型：**智者 Sage**——第一性拆解，交付方法。
- 叙事基调：发现 → 带回 → 拆解 → 交付。

**用法**：原型是叙事的内核，不是标签。每条内容的开场都问：
「这一期我是去发现什么，还是去拆解什么？」

### 4.2 人格五维（Aaker，1-5 分）

| 维度 | 分值 | 表现（已定稿） |
|---|---|---|
| 真诚 Sincerity | 5 | 接地气、诚实、务实 |
| 胜任 Competence | 5 | 严谨、方法化、可靠 |
| 刺激 Excitement | 3 | 现场感的兴奋，不用夸张话术取悦 |
| 精致 Sophistication | 2 | 不塑造精英距离感 |
| 粗犷 Ruggedness | 3 | 敢下场、敢进现场、不怕脏活 |

**用法**：内容评价时打分——比如一条视频氛围太「精致」了（旁白太播音腔、
镜头太摆拍），就是在往上浮 4 号维度，与定位冲突，改。

---

## 5. 步骤 ④ 差异化地图

### 5.1 对标差异表（已定稿，DESIGN.md §2.2）

| 对标类型 | 它们的形态 | 我的差异 |
|---|---|---|
| 鸡汤/成长博主 | 情绪共鸣、无证据口号 | 证据与真实反馈驱动 |
| 知识博主/课程 | 二手转述、系统化包装 | 一手田野 + 第一性拆解 |
| 测评博主 | 产品视角、参数速览 | 人与行业视角、真实使用反馈 |
| 纪录片/纪实 | 旁观者叙事、精致疏离 | 参与者视角、本人下场 |
| 效率/AI 博主 | 工具清单、流量驱动 | 先把身体/认知/AI 调到极致再谈工具 |

### 5.2 替代选择分析（April Dunford 框架）

1. 观众不看我的内容时会看什么？→ 书与课程 / 其他博主 / 纪录片与报道 / 朋友经验
2. 这些替代物共同给不了什么？→ **一手反馈 × 可照做系统 × 现场感**
3. 我的每条内容是否都在补这个缺口？→ 是，才算差异化成立

**注意**：差异表每季度重描一次——竞品会变，替代选择会变，
「我的差异」必须相对它们重算，而不能停留在去年的文档里。

---

## 6. 步骤 ⑤ 验收与校准

### 6.1 单条内容验收（发布前）
- [ ] 定位四问：目标受众适用？品类词对应？价值供给符合？差异证据可见？
- [ ] 署名换人检验：换成别人还成立吗？（不成立 ✓）

### 6.2 季度校准（每季度一次）
1. 重读定位陈述一句不差地复述吗？（记不住 = 定位不够锐利）
2. 过去 90 天内容：支柱覆盖率、与定位的相关性、偏离项盘点；
3. 重新描差异表（对标对象有无变化？）；
4. 需要改的，只改「表达」，不改「内核」——内核改一次需要更长的验证期。

## 7. 定位方法速查卡（贴在工位）

```
受众：25-40 系统型成长者（知识工作者/工程师/独立创作者）
品类：基于极致工程的田野调查笔记
价值：真实一手反馈 + 可照做系统
证据：现场实录 / 公开数据 / 原话可查
人格：真诚 5 · 胜任 5 · 刺激 3 · 精致 2 · 粗犷 3
禁止：速成承诺、二手观点、精英疏离、无证据断言
```
