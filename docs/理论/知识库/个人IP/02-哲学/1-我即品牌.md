# 02-1 我即品牌：不立人设

> 一句话：**品牌不是你的包装，品牌是你本人。任何「署名换成别人也成立」的输出，
> 都是在替别人做品牌；只有「换成别人就不成立」的东西，才是在建设自己。**

---

## 1. 为什么是「我即品牌」

| 常见做法（人设化） | 我即品牌（主体化） |
|---|---|
| 设计一个「人设」再往里填内容 | 从真实的自己出发，让内容长出来 |
| 人设是防御：怕被看穿 | 主体是开放：不怕被检验 |
| 人设会崩塌（一次不符即「塌房」） | 主体会成长（过去与现在可并存） |
| 人设在为「角色」积累资产 | 主体在为「我」积累资产 |
| 人设可以轻易复制 | 我的经历、判断、语言天然不可复制 |

**本质区别**：人设是「表演一个形象」，我即品牌是「在真实自我的延长线上持续输出」。
行业共识（Austin Kleon《Show Your Work》）：**不要假装「冷酷的专业人士」，公众更愿意
跟随一个有缺点的真实的人，而不是一个完美的角色。**

---

## 2. 一致性：唯一的检验标准

> 一致性检查（品牌蓝本 §4.3）：**任何内容拿出来，署名换成别人就不成立。**

换成别人就不成立，意味着内容里必须有**只有你才有的东西**：
- 只有你去过的现场、只有你见过的原话;
- 只有你吃过的亏、只有你调教出的数据;
- 只有你的说话方式、你的判断、你的犹豫。

这个标准同时是**选题过滤器**：凡是「谁都能做」的内容（纯转述、纯热点、纯观点搬运），
天然过不了这一关——它们不建设你，只消费你。

---

## 3. 身份一致性的三个层面

| 层面 | 含义 | 落地 |
|---|---|---|
| 内外一致 | 台前与私下是同一人 | 直播/拍摄/文字用同一口吻；不出现「台上人设、台下另一副面孔」 |
| 过去现在一致 | 不否认自己的来路与转变 | 承认曾经的误解/失败；明确标注「我以前的说法错了」 |
| 输出之间一致 | 各平台、各形式互相呼应 | 公众号长文、视频、短帖共享同一套观点与词库（对应 tone of voice 规范） |

**注意**：一致性 ≠ 不变。成长中的修正（合理更新）与崩人设（否认事实）的区别在于——
修正会说明理由，人设崩塌只会删帖。

## 4. 命名与身份资产

- 品牌名：**曹亚仑**（本名直用）。本名 = 承诺：「我为我说的一切负责」。
- 各平台 handle 统一为可辨识的同一 ID（现状 GitHub: allengaller，待统一，见品牌蓝本 §7.2）。
- 头像：真实生活照，非棚拍精修——「我即品牌」的第一视觉承诺。

**为什么不用艺名/马甲**：匿名的代价是「信用不可累计」。本名让每一次
输出都计入同一个信任账户；而信任账户的复利正来自账户一直是你。

## 5. 常见偏差自检

| 偏差 | 表现 | 修正 |
|---|---|---|
| 角色化 | 写内容时下意识扮演「专业博主」 | 复盘时问：私下会这么说话吗？ |
| 只晒高光 | 只发成功的过程 | 加发失败与踩坑——那是别人没有的素材 |
| 迎合算法 | 为流量改人设 | 流量是结果，不是标准 |
| 精神分裂 | 各平台口吻不一致 | 统一词库与口吻样本（DESIGN.md §5） |
