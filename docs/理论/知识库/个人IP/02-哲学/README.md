# 02 哲学 —— 个人 IP 的信念底座

> 逻辑回答「凭什么成立」，哲学回答「我是谁、我信什么、我拒绝什么」。
> 哲学不是鸡汤，它是**决策时的第一参照**：方法记不住时可以查文档，
> 但在利益、诱惑、压力面前，只有信念能拦住你。
>
> 本 IP 的哲学由一句话统领：**我即品牌，所有输出都是我；真实、极致、公开。**

---

## 1. 五条核心信念

```
┌────────────────────────────────────────────────────────────┐
│  1. 我即品牌   不立人设，输出即本人；署名换人即不成立       │
│  2. 真实优先   真实是最强差异化；说人话、给证据、认不知    │
│  3. 极致工程   第一性 + Maxing everything（身体/认知/AI）  │
│  4. 公开构建   过程、数据、失败全程公开（build in public） │
│  5. 长期与伦理 时间站在长期主义一边；边界即护城河           │
└────────────────────────────────────────────────────────────┘
```

| 信念 | 它保护什么 | 它禁止什么 |
|---|---|---|
| 我即品牌 | 不可替代的主体性 | 人设表演、第二人格 |
| 真实优先 | 信任资产 | 包装、二手充数、事后美化 |
| 极致工程 | 质量与独特性 | 半成品当坦诚、人云亦云 |
| 公开构建 | 复利与信用 | 只晒结果、数据造假 |
| 长期与伦理 | 可持续性 | 速成诱惑、越界采集、伤害受访者 |

## 3. 哲学怎么用（三个场景）

1. **选题时**：不符合「真实优先 + 极致工程」的选题，数据再好也不做（对应 04-思路 的四问）。
2. **遇到诱惑时**：一单商单、一次包装、一个热点——先问「这会违背哪条信念」。
3. **复盘时**：季度校准不只是看数据，更要看「本季度有没有任何输出违背了五条信念」——
   因为哲学的偏离不会立刻体现在数据里，但一定会体现在信任里。
