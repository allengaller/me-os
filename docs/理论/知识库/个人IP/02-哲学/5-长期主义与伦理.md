# 02-5 长期主义与伦理：时间站在谁一边

> 一句话：**个人 IP 是复利游戏，复利只奖励活得久的人。
> 活得久的条件有两样：稳定可持续的节奏，和绝不越线的伦理。**

---

## 1. 长期主义的三个时间尺度

| 尺度 | 周期 | 关注什么 |
|---|---|---|
| 战术 | 天/周 | 发布节奏、调教执行、当日反馈处理 |
| 战略 | 季/年 | 支柱覆盖、渠道健康、定位校准 |
| 存在 | 3-10 年 | 作品库厚度、信任资产、人生愿景对齐 |

**纪律**：
- 用战略尺度的标准决策，用战术尺度的节奏行动——**周更的质量由季度目标定义**；
- 短期数据波动不改变战略判断（单条扑街 ≠ 方向错误，先查环，再定论）；
- 每年至少一次「存在尺度」复盘：这套 IP 还在为我的人生愿景服务吗？
  （联动 docs/理论/方法论/方向/愿景.md）

### 长期主义的敌人（且都是诱人的）

| 敌人 | 样子 | 解毒剂 |
|---|---|---|
| 速成承诺 | 「30 天涨粉 10 万」的服务与套路 | 检验：它卖的是信任还是漏洞 |
| 追热点疲劳 | 为流量做与定位无关的内容 | 选题四问的第一问：有真实反馈吗 |
| 数据焦虑 | 以天为单位盯数据 | 数据看趋势与回看率，不看单日 |
| 完美主义停更 | 觉得没准备好就拖着 | 「发出去再改」>「准备到完美」；纠错机制兜底 |
| 疲态失速 | 节奏乱、质量降 | 降频不降质：宁可周更变双周，不发注水内容 |

## 2. 伦理的定位：边界即护城河

伦理不是「对观众的恩惠」，而是**资产保护制度**：
- 一次造假 = 多年信任资产清零（可对比：一次失误 + 公开更正 = 加分）；
- 边界清晰 = 决策省心（不用每次遇到诱惑都纠结）；
- 伦理克制 = 稀缺信任（在普遍低线的环境里，守线者自动获得溢价）。

### 2.1 田野调查伦理（受访者优先，品牌蓝本 §8.2 展开）

发布前逐项确认（固定为同意清单模板）：

- [ ] 已告知内容用途与发布平台
- [ ] 已确认出镜/引用范围（可只语音、只文字）
- [ ] 已选择署名或匿名（默认尊重匿名权）
- [ ] 关键引用已由受访者过目确认
- [ ] 已告知撤回权与联系方式
- [ ] 已完成感谢/回馈惯例

**红线**：受访者优先于内容。受访者反悔 → 删除该片段（无论多精彩）；
语境不能删到扭曲原意；绝不诱导受访者说出「更有节目效果」的话。

### 2.2 内容伦理

| 场景 | 规则 |
|---|---|
| 争议题材 | 呈现多方反馈与完整上下文，不预设立场 |
| 数据引用 | 可复核、标来源；无法复核的标明「估计值」 |
| 绝对化断言 | 清除（最强/没有之一/必看/震惊）|
| 隐私 | 他人隐私默认不拍不写；拍前征得同意 |
| 未成年人 | 出镜须监护人知情同意 |
| 商业合作 | 真实使用 + 调性一致 + 明确标注（03-方法/4 有全套标准） |

### 2.3 更正机制（把错误变成资产）

1. 发现错误 / 被纠错 → 24 小时内回应；
2. 核实（纠错优先：假定观众是对的，查证后表态）；
3. 正文修正 + 发布说明（评论区置顶 + 视频简介标注）；
4. 把纠错案例记入选题库（纠错即田野，也可能是好内容）；
5. 定期审计田野样本代表性：是否总在采访同一类人群、同一类立场？

## 3. 伦理冲突决策流程（当两难时）

```
场景：一条内容能带来 10 万播放，但需要：披露受访者未同意信息 / 夸大数据 / 断章取义
第 1 步：确认它属于「保密区/红线」（见 §2 与品牌蓝本 §8）
第 2 步：换算资产账：短期收益 ×1  vs  信任损失 ×10~∞（穿帮即清零）
第 3 步：找替代方案：这个价值能否不越线地实现？（匿名化、模糊化、改角度）
第 4 步：仍越线则放弃——并记录到复盘：为什么它是诱惑（写进 reviewNote）
```

**永远有替代方案**。觉得「不越线就做不成」时，通常是选题设计的问题，
而不是伦理规则的负担。

## 4. 长期主义的仪表盘（季度看一次）

| 指标 | 关注信号 |
|---|---|
| 作品库厚度 | 是否每月都在净增可回看的内容 |
| 回看率走势 | 90 天回看率升还是降（内容质量的时间检验） |
| 输出了解度 | 被引用/转载/邀请次数（信任与影响力外溢） |
| 伦理记录 | 本季度有无越线事件、有无公开更正（有更正 = 系统健康） |
| 哲学自检 | 五条信念（我即品牌/真实/极致/公开/长期）有无触碰 |

## 5. 检验清单（季度复盘用）

- [ ] 本季度内容是否全部经得起「署名换人」检验？
- [ ] 受访者同意清单是否每期都走完？
- [ ] 有没有任何「当时觉得没事」现在想删的内容？为什么当时会放过它？
- [ ] 我的节奏是否可持续？（而不是靠透支完成的）
- [ ] 下一季度我把长期资产（而非流量）投在哪里？

## 附：本 IP 的伦理锚点
