# 04-3 决策与筛选思维：用框架减少错误

> 一句话：**决策的数量要少，质量要高——把高频判断变成清单与矩阵，
> 把省下来的判断力留给真正不可代理的决策。**

---

## 1. 决策分层

| 层 | 决策 | 处理方式 |
|---|---|---|
| L1 日常 | 标题写哪个、封面选哪张 | 清单 + 直觉（快） |
| L2 重要 | 选题立项、回应争议、渠道调整 | 框架 + 矩阵（本文） |
| L3 战略 | 定位校准、商业化路线、年度主题 | 第一性 + 季复盘（慢） |

**原则**：L1 用清单免思考；L2 用框架防失误；L3 用季度守住节奏。
把 L3 的决策拖进 L2 的日常，是判断力最大的浪费。

---

## 2. 选题四问（L2 高频，核心决策）

全部通过才立项：

| # | 问句 | 不通过的样子 |
|---|---|---|
| Q1 | 有真实反馈可验证？ | 纯观点、纯转述、无现场无数据 |
| Q2 | 能拆到第一性？ | 只有故事没有理，拆两层就到底 |
| Q3 | 观众能照做？ | 听完只能「哇」，没有落地动作 |
| Q4 | 符合调性三关键词？ | 不接近真实 / 端着 / 无依据 |

**补充规则**：
- 四问之外再看「支柱归属」：说不清属于哪根支柱的选题 = 定位漂移信号；
- 同一主题三个月内不重复立项（除非有新的真实反馈）；
- 优先级：高 = 真实反馈 × 高普适；中 = 单点深入；低 = 过程记录。

---

## 3. 优先级矩阵（产能排布）

```
                影响（普适度/北极星贡献）
            低                高
        ┌──────────┬──────────────────┐
    高  │  ② 顺带做  │  ① 立即立项（主攻） │
性价比  ├──────────┼──────────────────┤
   低   │  ④ 放弃    │  ③ 储备（等时机）   │
        └──────────┴──────────────────┘
```

排布规则：
- ① 立即立项（主攻资源）；③ 储备（进选题库，等产能或时机）；
- ② 用一鱼多吃的边角料顺带做；④ 明确丢弃（丢的不只是选题，是消耗）。

---

## 4. 机会决策：做不做？（合作 / 渠道 / 活动 / 内容）

三问过滤（顺序不可换）：

```
① 属于我的定位与支柱吗？（不属于 → 直接否，不用看后面）
② 对我的哪个环有正向作用？（说不清 → 否）
③ 机会成本 > 收益吗？（挤占主攻选题的时间 → 推迟或否）
```

**「好机会」失效案例**：调性一致的合作邀约很诱人，但若挤掉了本月
田野长视频的主攻时间，就是飞轮减速——用 ②③ 问挡下。

---

## 5. 回应决策：发不发？（争议、热点、质疑）

```
① 事实核完没有？（没核完 → 不回应，先核实）
② 这是不是我的战场？（与我无关的争吵 → 不参战）
③ 我手里有完整上下文吗？（有 → 用上下文回应；没有 → 承认不知道）
④ 这个回应会留三年吗？（会丢人的措辞 → 重写）
```

**红线**：情绪上头时不发公共内容；深夜不发布；被激怒时先写进草稿箱，24 小时后再看。

---

## 6. 决策记录：决策日志（复盘用）

每季度记录 10-15 个 L2/L3 决策：

```
日期 | 决策 | 依据（框架哪步） | 结果 | 下次改进
─────────────────────────────────────────────
9-02 | 拒绝某商单 | 三问①不属定位   | 无损失 | 无
9-15 | 立项「外卖收入」 | 四问全过 + 高普适 | 成败待复盘 | —
```

用途：判断力是可训练的——训练数据就是决策日志。
