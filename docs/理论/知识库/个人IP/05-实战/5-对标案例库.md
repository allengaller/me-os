# 05-5 对标案例库：学什么，不学什么

> 用法：**对标是方法源，不是模仿对象**（品牌蓝本 §2.4）。
> 每季度更新一次：观测各对象的近况，提炼「这段时间他们在做的新动作里，
> 哪一个是值得借鉴的方法」——只吸收机制，不吸收形态与立场。

---

## 1. 对标总表

| 对象 | 领域 | 借鉴点（机制） | 不学什么（形态/立场） | 观测指标 |
|---|---|---|---|---|
| 《十三邀》 | 深度访谈 | 对受访者的尊重、不设防的对话 | 精英叙事与疏离感 | 提问姿态、如何对待沉默 |
| 《人生一串》 | 纪实美食 | 烟火气、接地气的现场感 | 栏目化包装套路 | 现场声音/人物如何处理 |
| swyx | 创作者方法论 | 学习过程公开化（learn in public） | 纯英文技术语境 | 过程公开的颗粒度与节奏 |
| levelsio | 独立开发 | 过程即产品、数据透明 | 争议性营销手法 | 公开了什么数据、如何互动 |
| Bryan Johnson | 身体系统化调教 | 身体数据化、可测量的调教 | 极端化生活方式 | 数据呈现方式、迭代逻辑 |

## 2. 分对象拆解

### 2.1 《十三邀》：访谈的伦理与姿态
- **学**：
  - 问题不预设答案，允许对话「走题」——受访者带着你走，比拽着对方走更有信息量；
  - 把「不舒适的沉默」留在成片里——沉默是真实的组成部分；
  - 后期的尊重：受访者的话不被消费式剪辑（对照：综艺式猎奇剪辑）。
- **不学**：知识分子咖啡馆式的精英距离感；把访谈变成个人思想秀。

### 2.2 《人生一串》：烟火气从哪来
- **学**：
  - 现场音效与环境的颗粒感（油锅声、人声、街景）——真实感由细节堆成；
  - 小人物叙事：不拔高、不煽情，让行业人物自己说话；
  - 克制旁白：解说只做连接，不做判断。
- **不学**：栏目化的包装套路（片头/章节体/金句结尾模板）。

### 2.3 swyx：learn in public 的方法颗粒度
- **学**：
  - 每步学习都有输出（笔记/推文/演示）——学即产，产即学；
  - 公开的「未完成感」：半成品可以发（发的是过程，不是垃圾）；
  - 把观众反馈直接并入学习路径。
- **不学**：纯英文技术自媒体语境；代码向的选题权重。

### 2.4 levelsio：过程即产品的实证
- **学**：
  - 数据透明：收入/流量/失败全部晒——透明本身就是信任策略；
  - 高频小步迭代：公开承诺 → 交付 → 复盘→ 再承诺（节奏的力量）；
  - 把「用户的实时画像与反馈」作为产品输入（对应本 IP：评论即田野）。
- **不学**：争议性营销（碰瓷式曝光、夸大标题）；把争议当增长手段。

### 2.5 Bryan Johnson：身体数据化的系统
- **学**：
  - 「测量 → 干预 → 复测」的闭环：调教必须有基线数据；
  - 身体即工程对象：睡眠/训练/饮食按变量管理，一次一个变量；
  - 数据公开的仪式感：用固定格式（周报/对比表）降低观众的理解成本。
- **不学**：极端化生活方式、过度医疗化、为对抗年龄的焦虑营销。

## 3. 借鉴的迁移规则（怎么把「他们的」变成「我们的」）

```
迁移三步：
① 提炼机制（它为什么有效）——不抄表面招式
② 映射到我的系统（对应哪个环/支柱/环节）
③ 小步试点（做一期实验内容，用 reviewNote 验证）
```

**示例迁移**（swyx 的公开化 → 本 IP）：
- 机制：在途项目过程公开；
- 映射：公开构建支柱的「调教日志」；
- 试点：「30 天睡眠-训练-LLM 管线改造」连载 → 数据与失败公开 → 验证回看率与高价值评论。

## 4. 观测方法（季度例行）

```
每季度：
① 快速扫一遍 5 个对标的近期代表作（各 1-2 条/篇）
② 记录 3 条「新动作」（他们最近在做什么以前没做过的事）
③ 迁移评估：哪些机制适用于我？（≥1 条进入下季度试点）
④ 清理：哪些借鉴已内化，撤出观测清单？有无新对标对象？
```

**候选扩展池**（按需加入）：影视飓风（工程化制作）、何同学（创意工程）、
半佛仙人（行业叙事化）、老爸评测（检测实证）、以及行业内持续出现的
「田野/纪实型」新创作者。

## 5. 反对标：明确不成为谁

| 形态 | 为什么不做 |
|---|---|
| 纪录片感团队 | 成本与调性都不匹配「本人下场」 |
| 标题党流量号 | 一次性流量 vs 信任资产，账算不过来 |
| 知识付费大师 | 系统性包装与「我即品牌」冲突 |
| 测评号 | 产品视角，不是人与行业视角 |
