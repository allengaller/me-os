# 05-1 零启动手册：从 0 到第一条视频（30 天）

> 目标定义：**第 30 天，发布第一条田野调查长视频，并写下它的 reviewNote。**
> 期间不以数据为考核，以「闭环跑通 + 系统建立」为考核。这是本 IP 唯一一次允许「练手」。

---

## 1. 启动前提（第 0 天确认）

- [ ] 读过 [01 逻辑](../01-逻辑/README.md) 与 [02 哲学](../02-哲学/README.md)，认同核心结论
- [ ] 品牌蓝本（DESIGN.md）定位陈述能背出来
- [ ] 不投入一分钱广告预算（前 30 天验证内容本身）
- [ ] 时间承诺：每周 ≥8 小时投入内容（确认可持续，再开始）

## 3. 第一个 30 天的「反向清单」（不做）

- ❌ 不追热点（先用 30 天把主线跑通）
- ❌ 不买量、不互推（连验证都做好，别污染数据）
- ❌ 不一次做 6 个栏目（只做：一个田野项目 + 每周一条调教日志短文）
- ❌ 不纠结设备（手机 + 领夹麦起步；「内容先成立」优先于「画质先专业」）
- ❌ 不因为数据差重做定位（30 天不足以判断定位，只能判断执行）

## 4. 首期选题的选型标准

| 标准 | 说明 |
|---|---|
| 好进 | 你已认识/能约到受访者（零启动期别选最难约的行业） |
| 好拍 | 有现场、有画面（工厂/门店/站点优于纯线上访谈） |
| 强反直觉 | 大众叙事与真实之间有落差（落差即钩子） |
| 不过度敏感 | 首期避开高危争议题材（隐私/争议复杂度留给第 2-3 期） |

**候选示例**（按此标准设计）：餐饮/汽修/外卖/物流/网约车等一线服务行业——
受访者密度高、现场感强、大众叙事丰富。

## 5. 启动完成的验收标准（第 30 天）

- [ ] 第一条田野长视频已发布，质量门记录齐全
- [ ] 首期 reviewNote 已写，「改进项 ≤3 条」
- [ ] 选题池存量 ≥ 15 条（下个月的弹药）
- [ ] 发布数据已入驾驶舱（哪怕数据=0，也要记录）
- [ ] 已确定第 31 天的下一项任务（不是「休息」，是「第二期立项」）

**之后的节奏**：进入 [4-运营节奏与复盘](./4-运营节奏与复盘.md) 的周期运转，
每月做一次月复盘，满 3 个月做第一次季校准。

## 6. 启动期常见翻车与解药

| 翻车 | 解药 |
|---|---|
| 30 天还没发布（完美主义） | 记住：第一条的使命是「被发布」，不是「被爆款」；质量门保证下限，完成大于完美 |
| 受访者约不到（挫败） | 换策略：先做「连续现场观察」（蹲点记录）再约访谈；3 人 ≥ 1 人+现场 |
| 数据全 0（怀疑人生） | 回看 30 天目标：考核的是闭环跑通；数据归入第 2-3 月复盘 |
| 一周没动（节奏断了） | 降频不降质：本周只完成「写选题池 5 条」也算动；不许两周连续零产出 |
