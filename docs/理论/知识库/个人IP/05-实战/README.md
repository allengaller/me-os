## 2. 实践的三条铁律

1. **标准 > 感觉**：SOP 存在的意义是让「状态不好的一周」也能产出合格内容；
   状态好时你在 SOP 之上发挥，状态差时 SOP 兜底。
2. **先跑通，再优化**：第一个 30 天目标不是「完美」，是「跑通闭环」——
   从田野到成片到发布到复盘，每个环节都走一遍，哪怕数据难看。
3. **任何模板，用不顺就改**：模板是起点不是终点。每季度把使用中
   的修改沉淀回文件本身（活文档约定，见 [总纲](../README.md) §5）。
