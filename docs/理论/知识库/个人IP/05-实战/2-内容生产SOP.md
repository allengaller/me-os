# 05-2 内容生产 SOP：一条内容从选题到发布

> 适用：所有内容形态（长视频/长文/切片）。按序执行，每步有产出物与质量门；
> 单人产能下，长视频从立项到发布建议控制在 **2-3 周**。

---

## 1. 全流程总览（9 步）

```
① 立项 → ② 备料 → ③ 田野/采集 → ④ 整理 → ⑤ 创作 → ⑥ 审校
→ ⑦ 回访/同意 → ⑧ 分发 → ⑨ 复盘
（①②③④⑤ 长视频；⑥⑦⑧⑨ 全形态通用）
```

---

## 2. 分步 SOP

### ① 立项（0.5 天）
- 输入：选题池
- 动作：四问全部通过（[04-thinking/3](../04-思维/3-决策与筛选思维.md) §2）→ 填立项卡：

```
┌─ 立项卡 ─────────────────────────────────────────┐
│ 主题：______________ 支柱：________ 优先级：_____ │
│ 四问：Q1 真实反馈□ Q2 第一性□ Q3 可照做□ Q4 调性□ │
│ 目标受众的收获（一句话）：________________________ │
│ 预期记忆点（一个反直觉数字/原话）：________________ │
│ 风险预判（争议？隐私？）：________________________ │
└──────────────────────────────────────────────────┘
```

### ② 备料（0.5-1 天）
- 第一性预拆解：现象/目标/事实/约束 四层草稿（4-思路/1）；
- 数据与资料预检索（标来源层级）；
- 受访对象名单（≥3 人）+ 邀约话术（见 [3-田野调查实战](./3-田野调查实战.md)）。

### ③ 田野/采集（1-3 天）
- 按田野七步走（[03-methods/3](../03-方法/3-田野调查方法.md)）；
- 同意清单当场完成（缺一项=素材不可用）；
- 产出：素材包（录音/照片/笔记）+ 同意记录。

### ④ 整理（1-2 天）
- 逐字稿（原话不改写）；数据核验（交叉验证，标估计值）；
- 可用片段标注时间码；上下文记录（防断章取义）。

### ⑤ 创作（3-5 天）
- 长视频按内容公式组装（[03-methods/2](../03-方法/2-内容方法.md) §3）：
  钩子 → 现场 → 真实反馈 → 第一性拆解 → 落地 → 互动；
- 主资产（长视频）完成后，**再**切衍生形态（先主后切）；
- 文案同步出长文版（结论先行）。

### ⑥ 审校（1 天，质量门强制）
- 编辑检查清单逐项过（[03-methods/2](../03-方法/2-内容方法.md) §5）：
  调性三关键词 / 证据出处 / 禁用词扫描 / 受访者同意 / 标题封面 / 署名替换；
- 标题 3 候选 + 封面 2 候选（均过「不标题党」关）。

### ⑦ 回访/同意（1 天，发布前 48h）
- 关键引用逐条发给受访者确认（同意清单收尾）；
- 确认记录留档（截图/邮件）。

### ⑧ 分发（1 天）
- 主阵地首发（B站/视频号 + 公众号）→ 24h 后切片矩阵（抖音/小红书/X）；
- 各平台形态与语气微调（[03-methods/4](../03-方法/4-分发与增长方法.md) §1）；
- 平台数据和评论开始入档。

### ⑨ 复盘（发布 3-7 天后）
- reviewNote（[03-methods/5](../03-方法/5-复盘与迭代方法.md) §2）；
- 高价值评论逐条记录 → 回流选题池；
- 改进项 ≤3 条，全部可验证。

## 3. 各形态的附加规格

| 形态 | 规格要点 |
|---|---|
| 田野长视频 | 15-30min；原话上屏；反馈与观点分离标注 |
| 调教日志（周更短文） | 数据先行（基线→干预→结果）；失败也写 |
| 深度长文 | 结论先行（TL;DR）→ 现场故事 → 证据 → 方法 → 清单 → 局限 |
| 切片（抖音/视频号） | 15-60s；前 3 秒给结论；不破坏原语境 |
| 金句图文（小红书） | 原话 + 视觉；少术语 |
| 过程帖（X） | 数据/进度/复盘片段；可英文 |

### 3.1 试点条款 B3：田野长视频 beat 节奏法（迁移自 06 全球思维库）

> 机制来源：内容工程流派（MrBeast/Paddy Galloway 的前 5 秒 + 每 30 秒 beat 法）。
> 目标：验证结构化节奏能否提升完播率与 90 天回看率——用数据决定是否固化为剪辑标准。

| 项 | 内容 |
|---|---|
| 目标 | 连续 3 期田野长视频，每期达成「前 15 秒留存目标」（基线 ≥60%） |
| 验证指标 | 前 15 秒留存率、整体完播率、（发布 90 天后）回看率 |
| 时间窗 | 连续 3 期（一个季度内） |
| 步骤 | ① 剪辑前按 beat 结构出「节奏表」：前 5 秒钩子（反直觉发现/原话）→ 每 30-60 秒一个 beat（新原话金句/新数据点/转折）→ 结尾互动点 → ② 按表剪辑 → ③ 每期发布 72 小时后记录完成率 → ④ 3 期后对照「直觉剪辑」的历史均值 |
| 退出条件 | 3 期完播均值 ≤ 历史直觉剪辑均值，则放弃固化，恢复直觉剪辑并复盘原因 |

## 4. 产能分配（单人，月度基线）

```
月产能 ≈ 田野长视频 1-2 ＋ 调教日志 4 ＋ 深度长文 2-4 ＋ 切片若干
排期原则：长视频错峰（不连续两周都做田野）；
        调教日志固定每周（用模板把单篇压到 1-2 小时）。
```

**断更保护**：日历里预排 2 个「缓冲周」（不排重要交付），
突发占用的优先级：受访者 > 审校 > 发布 > 文案。

---

## 5. 质量门失败的处理规则

| 失败项 | 处理 |
|---|---|
| 调性偏离 | 返工重剪/重写（不是「先发再改」） |
| 证据缺失 | 补证或删除该断言（删 > 标「大概」） |
| 受访者不同意 | 撤片段；素材再好也撤 |
| 标题/封面标题党 | 回炉（标题党是信任税，一票否决） |
| 署名替换成立 | 回炉：内容里没有「只有你」的东西 |

## 6. SOP 自检（每周五）

- [ ] 本周立项是否都有立项卡？
- [ ] 在产内容处于哪一步？有没有超过步骤时限两周的僵尸项？
- [ ] 质量门记录是否随文件归档？
- [ ] 下周排期是否已确定（含缓冲周）？
