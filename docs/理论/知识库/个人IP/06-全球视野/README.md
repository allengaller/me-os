## 3. 使用方式（三步）

1. **查**：按问题找流派（→ 对应主文档）；
2. **提**：从该流派提取「机制」而不是「形态」（他的爆款题目不是你的，他的公式可以是你的）；
3. **迁**：用 [8-迁移总表](./8-迁移总表.md) 的「迁移三步」把机制映射到本 IP，小步试点验证。

**定位提醒**：本 IP（基于极致工程的田野调查者）在版图上的位置 =
① 定位流派强调的「细分垄断」× ② 创作流派的「show your work」×
⑤ BIP 的「过程公开」× ④ 内容工程的「可复制质量」——四者的交集，正是本套体系与全球思想的接缝。
