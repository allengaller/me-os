## 1. 迁移三步（每季度执行一次，每次 ≤3 项）

```
① 提机制：从 06-1 ~ 06-7 中选一条与本季目标最相关的机制
② 映射：它对应本 IP 的哪个环/支柱/环节？（说不清对应 = 不迁）
③ 试点：设定可测指标，跑一个季度，用数据决定「固化 or 放弃」
```

## 3. 全球思维与本 IP 的冲突调和表

## 5. 使用规则

1. **本表每季度校准一次**：试点项验收 → 升为 A / 放弃；评估项推进条件检查；
2. **每次只推 ≤3 项**（B 区试点最多并行 2 项，避免产能超载）；
3. **任何机制进入 A 区**，必须同时更新对应系统文档（03-方法 / 05-实践），
   否则不叫「内化」，叫「收藏」；
4. **新增思想人物**：先写进对应流派文档，再在总表登记影响。
