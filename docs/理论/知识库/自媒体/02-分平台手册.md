# 分平台手册：9 平台作战地图

> 定位：每个平台一章「作战地图」，回答六个问题 —— 这平台是谁？流量怎么给？内容怎么做？怎么涨？数据多少算好？怎么变现？
> 读法：先定主战场（见 01 §9），再查对应章节；指标为 2026-09 参考线，只跟同平台自己比。
> 平台优先级分层：**T1 视频主线（深度手册）** → B站 / 抖音 / 视频号 / YouTube；**T2 图文与社区** → 小红书 / 公众号 / 知乎；**T3 广播与轻量** → X / 微博。自建渠道（custom）按 T3 规则自定义。
> 合规与应用细则以各平台后台「规则中心 / 创作者学院」最新版为准，本手册只列原则与参考线；参考线逢 1 / 7 月校准（见 01 §6.4）。

## T1-1 B站（Bilibili）

**平台画像**：18–30 岁学生与年轻白领为主；弹幕社区文化；中长视频心智 + 知识付费意愿高；用户对「真诚与专业」极敏感。

**算法与分发**：
- 推荐流：完播率 + 互动（三连/弹幕）+ 观众画像泛化，是主流量入口
- 搜索流：知识/教程类内容搜索占比高，标题与关键词要 SEO
- 关注流弱于推荐流，粉丝价值在「开播通知」与私域
- 2024–2026 平台明显扶正中视频与直播（充电/工房/课堂）

**内容规格**：
- 横屏 16:9；深度 8–20min（知识区 10min+ 是舒适区）
- 标题 ≤30 字、点题清晰；封面 16:9 大字信息
- 分区 + 3 个标签；视频简介可放图文版/时间轴

**爆款规律**：
- 前 3 秒：冲突 / 承诺 / 反常识，B站用户耐心极低
- 信息密度：每 30 秒一个信息点；数据可视化、截图、时间轴是 B站 加分项
- 「专业 + 人味」：有观点、有态度、有个人经历，而非念稿

**冷启动路径**：
- 新号有基础流量池（数百到几千），稳定周更 3 个月是标准打法
- 弹幕引导（埋互动点）+ 细节彩蛋制造「发现感」
- 爆款后 48h 内更一条同系列承接

**数据健康线**：完播率 ≥25%（10min 档）可追投；48h 三连率 ≥1%；涨粉率（涨粉/播放）≥2%

**商业化**：创作激励（保底零花）→ 充电/工房（知识付费）→ 品牌商单（垂类 1–5 万粉可起步，优质垂类单价高）→ 直播

**雷区**：标题党（会被打分降权）、洗稿（UP 主圈最敏感）、低质批量、接灰产商单毁账号

**本品牌打法**：田野调查长视频主场。系列化栏目（如「极致工程」季更），每集末尾 CTA 引导关注 + 充电；视频简介挂调研资料/时间轴；与公众号深度文互链。

## T1-2 抖音（Douyin）

**平台画像**：全人群泛流量；兴趣推荐；强情绪刺激；用户时长与商业化深度（直播/电商/本地生活）业内第一梯队。

**算法与分发**：
- 流量池阶梯：初始 200–500 播放测试 → 完播/互动/转粉达标进 3000–1万 池 → 逐级放大
- 核心权重：完播率 > 互动率 > 转粉率 > 分享率（大体次序）
- 搜索流量占比持续上升（2024+），关键词布局不再可忽略
- 2026 场域 = 推荐 + 搜索 + 商城 + 本地生活

**内容规格**：
- 竖屏 9:16；15s–3min 主流（30–60s 是黄金区间）
- 标题 ≤20 字 + 话题 2–3 个；前 3 秒决定生死（划走即失败）
- 字幕必须清晰（大量用户静音刷）

**爆款规律**：钩子（冲突/悬念/利益前置）、情绪价值（爽/共鸣/涨见识）、热点借势（时效 24h 内）、真实感（现场/demo/过程）

**冷启动路径**：
- 起号期建议 1–3 条/天（轻量内容）或 3–5 条/周（重度内容），宁少勿碎
- 每条做标题 A/B（不同文案发两条对比）
- 发布 2h 看数据：完播 <20% → 改开头；互动差 → 换选题类型
- 先验证内容再上投流（内容没验证就投 = 烧钱买教训）

**数据健康线**：完播 ≥30%（1min 内）；互动率（赞评转/播放）≥3%；单条 5000+ 播放算过起号线

**商业化**：星图广告 → 直播带货/橱窗 → 知识付费（低客单）→ 本地生活探店

**雷区**：搬运（查重极严）、低俗诱导、导流词违规（微信话术有专门处罚）、过早投流、数据焦虑（播放波动极大属常态）

**本品牌打法**：切片矩阵主场。主视频（B站/YouTube）剪 30–90s 爆点切片日更；极致工程 demo 短爆点；合规导流（主页/评论区置顶按平台规范）；不做人设表演，只做「现场感」。

## T1-3 视频号（WeChat Channels）

**平台画像**：微信生态原生，30–60 岁用户占比高；熟人社交语境；公私域联动能力全平台最强；直播电商红利期（2023–2026 平台全力推）。

**算法与分发**：
- 社交推荐（朋友点赞/转发/在看）+ 兴趣推荐 + 搜一搜，双通道
- 私域（公众号/社群/朋友圈）是冷启动燃料，公域冷启动极难
- 直播有独立流量池，与短视频互哺
- 内容可直挂公众号文章、小店商品、企业微信

**内容规格**：
- 竖屏为主（横屏可兼容）；1min 内卡点短内容 + 3–15min 深度内容两条腿
- 标题与公众号联动；可设置合集
- 直播切片（1–3min）是短视频冷启动捷径

**爆款规律**：真实人设、共鸣/争议话题（中老年话题敏感度不同）、「替我说了」的转发逻辑、直播名场面切片

**冷启动路径**：
- 朋友圈 + 社群首发，用公众号/群撬「第一波 100 播放」
- 朋友点赞破圈机制：前 100 个播放的点赞率决定推荐
- 周 2–3 条稳定 + 每月 2–4 场直播（哪怕 30 分钟聊天局）
- 与公众号图文、直播、社群四件套联动（视频号是私域闭环的漏勺）

**数据健康线**：完播 ≥30%；分享率（转发/播放）≥3%；直播场均在线 50+ 及格、100+ 良好

**商业化**：直播（微信豆 + 带货）→ 小店 → 广告主互选 → 私域转化（课程/服务/高客单是真正主场）

**雷区**：搬运（查重高于抖音）、诱导点赞/转发（违规）、只发不互动（社交平台交流感是根本）

**本品牌打法**：与公众号 + 社群联动做深度分发；田野调查长视频搬视频号 + 直播「田野现场」切片；私域承接（课程/作品库导流）是视频号的战略价值，不是播放量。

## T1-4 YouTube

**平台画像**：全球市场；搜索 + 订阅双心智；长视频付费意愿最强；英语内容红利大；创作者「长期主义」文化（数字资产属性）。

**算法与分发**：
- 双引擎：点击率（CTR）+ 观看时长（AUDS）；前 30 秒决定留存
- 搜索 SEO：标题（<60 字符）/描述（前 150 字符）/章节 timestamps/字幕，教程类内容搜索占比高
- Shorts 是独立入口（导流工具，非主页资产）
- 推荐权重：观看时长比重 > 完播率，长视频更占优

**内容规格**：
- 16:9；8–20min 最佳（教程类 10min+）
- 缩略图（Thumbnail）决定 CTR —— 这是 YouTube 与国内平台最大的不同
- 章节 timestamps + 英语/双语字幕（爆款放大 10 倍的杠杆）

**爆款规律**：缩略图 + 标题钩子（文案能力>画面）、系列化（频道场景化）、信息密度、全球化选题（「工程/方法/实验」类通吃）

**冷启动路径**：
- 前 30 天连续上传 10–20 条（哪怕每条 5 分钟），建立频道声量
- 目标先行：每条 CTR ≥5%，否则换缩略图
- Shorts 引流长视频（1:5 比例）
- 订阅引导（片头 30s 内 + 片尾 30s）

**数据健康线**：CTR 4–10%；AUDS ≥50%（8min 档）；48h 观看 500+ 算法开始加速

**商业化**：AdSense（1000 订阅 + 4000h）→ 频道会员 → SuperChat → 品牌合作（海外单价高）→ 购物

**雷区**：版权音乐（AdSense 直接扣钱）、标题党（审核 + 差异化加权惩罚）、断更（频道记忆强）

**本品牌打法**：田野调查全球分发主场。中文原版 + 英文/双语版（或 AI 配音英文版）；「（极致工程）How Engineers Overthink Life」类全球化选题；build in public 系列可做英文 Shorts。YouTube 是「作品库」型资产，与价值观最合。

## T2-1 小红书（Xiaohongshu / RED）

**平台画像**：一二线城市女性为主（职场/生活方式/知识/消费决策），种草心智；**搜索驱动**（搜索流量占比过半）；用户「收藏」习惯全平台最强；信任成本低、决策快。

**算法与分发**：
- 笔记 CES 评分：点赞/收藏/评论/关注/转发加权 → 决定进入下一级流量池
- 搜索权重：关键词出现在标题/正文前 20 字/标签中，命中即长尾
- 视频笔记（1–3min）与图文笔记同池竞争；图文信息密度更吃香

**内容规格**：
- 图文 3:4 或 1:1；封面大字标题（封面上写结论是标配）
- 标题 ≤20 字 + 关键词前置；emoji 克制使用（行业共识：少而准）
- 正文首行即结论，清单化排版；话题标签 3–5 个

**爆款规律**：收藏率（干货/模板/清单被收藏）> 点赞率；封面信息量（一屏说完）；情绪共鸣（「我终于搞懂了」）；真实使用体验；季节/节点借势

**冷启动路径**：
- 垂直领域 30 天日更或隔日更（图文日更成本低）
- 拆解 20 篇同垂类爆文结构（封面/标题/正文骨架）
- 评论区运营：置顶引导收藏 + 认真回复（评论区权重高）
- 笔记发布后 1h 内互动决定初始推送

**数据健康线**：爆文率 ≥10%（100 篇中 ≥10 篇互动率超基线 2–3 倍）；收藏率 ≥2%；涨粉率 ≥2%

**商业化**：买手电商（笔记挂车）→ 蒲公英品牌合作（报备）→ 聚光投放 → 私域合规转化（课程/咨询）

**雷区**：硬广不报备（限流+封禁）、导流微信违规（最高处罚）、同质化搬运（平台查重严）、数据注水账号

**本品牌打法**：图文知识卡主场。封面「结论大字 + 视觉符号」固定模板（形成识别度）；收藏导向设计（提供可保存的模板/清单/工具）；与主视频联动（视频笔记形式分发切片）；「极致工程」类内容在小红书高客单人群里价值密度高。

## T2-2 公众号（WeChat Official Account）

**平台画像**：深度阅读场景；中年职场高净值人群；信任与私域变现力全平台最强；打开率整体下行但信任密度上行。

**算法与分发**：
- 订阅消息（关注用户）+ 看一看推荐（2024+ 推荐占比上升）+ 搜一搜/问一问
- 推荐流量 = 完读率 + 在看/点赞 + 关注转化加权
- 搜一搜是长尾流量（关键词布局可吃几年）

**内容规格**：
- 长文 2000–5000 字；排版克制（1.75 行距、高清图、小标题、清单）
- 封面 2.35:1（转发卡片形态）；标题 ≤20 字 + 关键词
- 底部留 CTA（关注/在看/赞赏/加群）；自动回复引流

**爆款规律**：深度选题（痛点 + 方法论 + 案例）、标题公式（数字/冲突/结果/悬念）、首图与标题「搜索 + 点击」双优化

**冷启动路径**：
- 周更 1–2 篇（深度文）为常规；启动靠朋友圈 + 社群 + 其他平台导流
- 搜一搜 SEO：长尾关键词写进标题与前 100 字
- 转载互推：与同量级账号互推一次 ≈ 一次合格投放

**数据健康线**：打开率 ≥3%（老号）；完读率 ≥30%；在看率 ≥0.5%

**商业化**：流量主（保底）→ 付费阅读/赞赏 → 广告主互选（中高单价）→ 自有产品（课程/服务/作品库，高客单主场）

**雷区**：标题党（推荐降权）、洗稿（原创保护投诉）、排版本墙（大段文字无结构）、违规导流

**本品牌打法**：长文主场 —— 田野调查文字完整版、方法论专栏、工程复盘深度文；「品牌 Hub」与作品库的理想承载地；与视频号直播、社群联动是私域闭环核心。

## T2-3 知乎（Zhihu）

**平台画像**：高知男性占比高；**问题搜索心智**（用户带着问题来）；专业信任氛围；长文问答生态；内容生命周期长。

**算法与分发**：
- 问题流量 + 推荐流 + 搜索三通道；收藏是核心正向信号
- 盐值/创作分影响分发权重；「好回答」会被反复推荐数年
- 关注 vs 非关注：强问题场景下非关注用户也能看到高质量回答

**内容规格**：
- 回答 500–3000 字；结论先行 → 证据/案例 → 提炼清单
- 小标题 + 列表排版；可图文/视频混排
- 专栏（连续长文）+ 圆桌（话题运营）+ 想法（短内容）

**爆款规律**：回答即需求（问题即流量入口）、专业 + 真实案例、争议问题站队清晰、干货式清单（收藏型答案）

**冷启动路径**：
- 每天回答 1–2 个垂直问题：选「有流量、竞争适中」的问题（浏览量高 + 回答数 100 内）
- 热榜问题抢首答；高赞答案定期迭代更新
- 简介打造专业人设；回答末尾自然带出个人专栏/内容

**数据健康线**：赞同率 ≥2%（赞/浏览，好答案基线）；收藏率 ≥3%（收藏型答案）；回答→关注转化 ≥0.5%

**商业化**：知+ 投放 → 好物推荐（带货）→ 品牌任务 → 付费咨询/盐选 → 私域导流（注意平台规范）

**雷区**：营销号感（社区极敏感）、复制粘贴、擦边引流、付费咨询放鸽子（人设崩塌）

**本品牌打法**：「方法论回答」主场 —— 「如何做田野调查」「如何建立个人操作系统」「极致工程的执行细节」类问题；每条回答是品牌的信任证据；专业回答末尾链接公众号/视频（合规互链）。

## T3-1 X（Twitter）

**平台画像**：全球科技/创投/开发者圈层；实时新闻；build in public 文化原生土壤；英文互动价值 > 中文（看目标）。

**算法与分发**：
- For You 推荐流（互动/回复权重高）+ 关注流 + 搜索
- 时效极强：热点窗口以小时计；观点/数据/实物截图是燃料
- Threads 长帖（分段发布）适合深度内容；X Premium 有流量加权与广告分成资格

**内容规格**：
- 短帖 1–3 句 / Threads 5–15 段；图片与 1–3min 视频混排
- 英文内容（面向全球圈层）建议英文或双语
- 话题标签克量使用（1–2 个）

**爆款规律**：观点锐度（站队清晰）、数据/截图可视化、build in public 过程实录、行业热点锐评（30min 内跟上）

**冷启动路径**：
- 日更 2–5 条：1 条高质量观点 + 1 条过程实录 + 若干互动回复
- 引用/回复同领域 KOL（真实互动，不是刷屏）
- 参与 Space 语音房、话题标签；互关互刷会被算法惩罚
- 稳定 2–3 个月，涨粉 50–100/周即可

**数据健康线**：互动率（展示→互动）≥1% 算好；转推/点赞比高 = 观点尖锐；涨粉 50–100/周（起号期）

**商业化**：X Premium 广告分成（需 Premium + 粉丝 ≥500）→ 订阅（Super Follows）→ 品牌合作（海外）→ 导流 YouTube/Newsletter/作品库

**雷区**：买粉、垃圾互关、搬运截图侵权、政治敏感内容限流（按目标人群规避）

**本品牌打法**：build in public 日更主场（中英双语）。工程复盘瞬间（截图 + 短链）、田野调查过程中的一手观察、月度总结 Threads；导流 YouTube 长视频与作品库；与全部平台联动发（T3 = 广播器）。

## T3-2 微博（Weibo）

**平台画像**：全人群广场式广播；热搜文化；明星/时事/情绪内容为主；泛流量、转化弱。

**算法与分发**：热搜话题（自带流量但时效 24h）+ 关注流 + 超话社区；头部集中，流量向大 V 集聚。

**内容规格**：短帖 + 头条文章；九宫格；话题标签 1–2 个；视频 1–3min。

**爆款规律**：热点借势（全平台时效最快）、情绪表达与锐评、事件当事人/亲历者视角。

**冷启动路径**：日更 1–2 条 + 蹭垂类超话；参与话题讨论；与大 V 真实互动（评论被看到）。

**数据健康线**：转评赞/阅读 ≥1%；热搜可遇不可求，不做 KPI。

**商业化**：微任务/广告 → 微博小店带货 → 导流（弱，非主阵地）。

**雷区**：敏感话题（处罚严厉）、营销号外显、抽奖违规。

**本品牌打法**：「创始人发言」广播站 —— 重要节点发声（产品发布/调研发布/观点声明），联动转发其他平台内容；不投入主要精力，保持存在感即可。

## 落地总原则

1. **主次分明**：T1 投入 60%、T2 30%、T3 10%（时间而非心力；T3 用「顺手」心态）。
2. **一平台一定位**：同一内容每个平台有一句差异化定位（B站是作品、抖音是爆点、小红书是知识卡、X 是过程）。
3. **数据只跟自己比**：跨平台不可比（口径不同），周环比 > 绝对数。
4. **custom 渠道**：自建渠道（Newsletter/独立站/App）走「私域 + 作品库」逻辑，优先服务信任沉淀与高客单转化，不计入流量 KPI。
