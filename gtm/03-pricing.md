# 03 — 商业模式与定价（Business Model & Pricing）

> 回答「怎么收钱、何时收钱、免费与付费的边界在哪」。
> 结论先行：**Phase 1–3 完全免费开源，不设任何付费墙；Phase 4 以 open-core + 云托管订阅变现**。过早商业化会摧毁本地优先项目的社区信任，而社区信任是这个项目唯一的冷启动资产。

---

## 一、商业模式：Open-Core 三层

```
┌────────────────────────────────────────────────┐
│  L3 云服务（Phase 4，付费）                       │
│  云同步 · 移动端入口 · 托管实例 · 技能云端运行        │
├────────────────────────────────────────────────┤
│  L2 生态分成（Phase 3，探索）                      │
│  Skill 市场 / 官方认证连接器的可选付费分发           │
├────────────────────────────────────────────────┤
│  L1 开源核心（永久，MIT）                          │
│  五维全模块 · MeLog · 品牌板块 · MCP · 连接器框架    │
└────────────────────────────────────────────────┘
```

**承诺**（写进 README 与 Landing page，是定价策略的一部分）：
- L1 永久开源且功能完整（不是阉割版试用）
- 数据格式（MeLog Standard）永久开放，随时完整导出
- 自托管用户永远不依赖任何 MeOS 官方云服务

## 二、价值指标（Value Metric）选择

个人产品不适合按席位收费（用户数恒为 1）。候选指标对比：

| 候选指标 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 云同步存储量 | 成本强相关、随使用增长 | 认知成本高 | 作为 Pro 限额而非主计价 |
| 同步设备数 | 直觉清晰 | 易被绕过 | 辅助限制 |
| 技能云运行次数 | 与 AI 成本相关 | 波动大 | 包含额度 + 超量加购 |
| **固定订阅 + 用量限额** | 简单、可预期 | — | ✅ 采用 |

## 三、定价草案（Phase 4 上线时校准）

| 档位 | 价格（假设） | 内容 | 对应画像 |
|---|---|---|---|
| **Free** | ¥0 / 永久 | L1 全部：自托管全功能、社区支持 | 全部（转化入口） |
| **Pro** | ¥39/月 或 ¥390/年（假设） | 云同步与备份、移动端完整入口、LLM 技能托管（免配置 API Key）、高级技能市场、年度报告生成 | Persona 2/3 |
| **Founder Edition** | ¥1990 终身（限量，假设） | Pro 终身 + 名字进支持者名单 + 路线图投票权 | Persona 1 中的铁杆支持者 |

> 参照系：Obsidian Sync $4–8/月、Reflect $10/月、Notion Plus $10/月、Raycast Pro $8/月。Pro 定在「一杯咖啡出头」区间，年付 8–9 折。
> LLM 技能托管的成本随 token 价格变化，定价需按实际用量数据回归，上表仅为锚点。

## 四、免费与付费边界原则

1. **付费用 cloud，不付费用 feature**：付费买的是托管/同步/便利，不是解锁功能按钮
2. **不制造数据焦虑**：任何时刻可完整导出（Standard JSON + SQLite），取消订阅不锁数据
3. **学生/早期贡献者**：GitHub 贡献者（≥1 个 merged PR）获赠一年 Pro —— 把定价表变成贡献激励
4. **企业/商用咨询**：白标或内网部署需求出现时再谈，不主动做

## 五、商业化前必须成立的三个前提（Phase 4 Gate）

| # | 前提 | 衡量 |
|---|---|---|
| 1 | 活跃基本盘存在 | opt-in 周活 ≥ 1000（见 06 分册） |
| 2 | 有人愿意为云托管举手 | Waitlist ≥ 300（Phase 3 在 Landing page 挂出收集） |
| 3 | 运维成本可承受 | 云同步/PoC 成本模型算清，LTV > 3×CAC（初期 CAC≈0 时看单位经济可行） |

## 六、风险与对策

| 风险 | 对策 |
|---|---|
| 「开源了还收费」的社区反弹 | 收费对象是云服务（业界惯例：Obsidian/GitPod/Supabase 同款），发布前在 Discussions 发定价 RFC 征集意见 |
| 白嫖不付费 | 接受——L1 用户本身就是生态与口碑的一部分，Persona 3 的 Pro 转化靠品牌板块深度绑定 |
| 竞品（大厂）下场做同品类 | 差异化在「开放标准 + 创始人 IP + 方法论文档」；标准协议是被收购/共存时的谈判筹码 |
| 收入不及运维成本 | 云服务规模不经济时收缩为「Pro = 本地增强包」，保持不烧钱运行 |
